# 手動回帰チェックリスト

結果欄には、確認日、AviUtl2版、SRTrackコミット、結果を記録する。

| # | 操作 | 期待結果 | 結果 |
| --- | --- | --- | --- |
| P1 | 0〜30秒を再生・シークする | Layer 2 の SRTrack Object が `regression-video.srt` の各3秒区間をPreview表示する | |
| P2 | 動画の再生速度または再生開始位置を変更する | Layer 2 のPreviewが動画再生位置に追従する | |
| P3 | Layer 1 の動画を一時的に別レイヤーへ移す | Layer 2 のPreviewは「1つ上のレイヤーに動画がない」診断を表示する | |
| P4 | 28秒へシークする | Standalone Object が `Standalone A`、29秒付近で `Standalone B` を表示する | |
| E1 | 初期設定でシーン全体をExporter出力する | SRTrack Object、Standalone、テキストObjectの字幕候補を含むSRTになる | |
| E2 | 12〜18秒の `<r10>AB<c0.5>CD` を初期設定で出力する | 1秒未満の候補は最小表示時間 `1.000` 秒の規則で結合・延長される | |
| E3 | 最小表示時間を `0.500` にしてE2を再出力する | `AB` と `CD` のクリア境界を確認できる | |
| E4 | 20〜22秒を出力し、並び順を上下で切り替える | 同時開始の `上` と `下` の本文順だけが反転する | |
| E5 | 24〜28秒を出力する | 既定では `漢字（かんじ） （拍手） 装飾` 相当。コメント・Lua・装飾制御文字は残らない | |
| E6 | E5でルビ・絵文字のチェックを順にオフにする | 対象のルビ読み・絵文字だけが削除される | |
| E7 | フレーム範囲選択で3〜6秒を出力する | 範囲先頭が `00:00:00,000` となり、境界字幕が切り出される | |
