| P2 | 30〜45秒を再生・シークする | 同じ基準SRTが動画の2倍速に追従する | |

| P6 | 90〜105秒を再生・シークする | fix Objectが全長5秒を周期に `[SRTrack] FIX-A`、`FIX-B` を繰り返してPreview表示する | |
| P7 | 150〜180秒を再生・シークする | 前半の動画終了後は専用診断になり、動画再出現後は `P=20` 秒に対応する `映像基準 G` 以降を表示する | |
| P8 | 180〜210秒を再生・シークする | 180〜195秒は通常速度、195〜210秒は同じ動画の2倍速として、それぞれの対応字幕を表示する | |
| P9 | 210〜216秒を再生・シークする | 動画と SRTrack Object の間に空の非動画テキストObjectがあっても、`映像基準 A`・`B` が Preview表示される | |

| P11 | `SRTrack 設定` で「編集画面に字幕プレビューを表示する」をオフ／オンに切り替える | 個別Preview設定を保ったまま全Previewが非表示／再表示される | |
| E1 | 初期設定でシーン全体をExporter出力する | すべての固定ケースを含むSRTになり、出力結果をテストマップと照合できる | |
| E2 | E1の105〜110秒付近を見る | `SIM-A`〜`SIM-D` が上のレイヤーから本文順に結合される | |
| E3 | E1の110〜128秒付近を見る | 時間制御文字が本文に残らず、基準の最小表示時間1.000秒で結合・延長される | |
| E4 | 最小表示時間を `0.500` にして再出力する | `AB`／`CD`、待機、倍率付きクリアの境界を観察できる | |
| E5 | E1の128〜134秒付近を見る | `漢字（かんじ） （拍手） 装飾` 相当。コメント・Lua・装飾制御文字は残らない | |
| E6 | E5でルビ・絵文字のチェックを順にオフにする | 対象のルビ読み・絵文字だけが削除される | |
| E7 | E1の134〜140秒付近を見る | `INTERRUPT` 開始で元SRT字幕が中断し、次の元SRT字幕は本来の開始で始まる | |
| E8 | E1の140〜150秒付近を見る | 動画が続いてもObject終端で字幕候補が終了する | |
| E9 | フレーム範囲選択で任意区間を出力する | 範囲先頭が `00:00:00,000` となり、境界字幕が切り出される | |
| E10 | E1の150〜180秒付近を見る | 動画不在の10秒間は字幕がなく、再出現後は `P=20` 秒に対応する字幕が再開する | |
| E11 | E1の180〜210秒付近を見る | 動画切替境界で前の動画の字幕が終了し、次の動画の再生位置・速度に対応する字幕が始まる | |
| E12 | E1の210〜216秒付近を見る | 空の非動画テキストObjectを読み飛ばし、`映像基準 A`・`B` が出力される | |
| E13 | E1の216〜222秒付近を見る | `TXT-NOTE: SRT にのみ出力する補足字幕` がObject範囲の一字幕として出力される | |
| E14 | E1の222〜233秒付近を見る | `MIN-EXACT-A` は単独で1秒まで延長され、`MIN-LATE-A` も `MIN-LATE-B` と結合されない。`MIN-CHAIN-A`〜`C` は一つの字幕として結合される | |
| E15 | 216〜222秒の `TXT-NOTE` の末尾0.5秒だけをフレーム範囲選択して出力する | 選択開始が `00:00:00,000` となり、短く切り詰められた字幕が選択範囲外まで最小表示時間へ延長される | |
| E16 | 最小表示時間を `0.500` にして、233〜243秒を出力する | `AあB` の待機・クリア後の `C` は各0.9秒後、ルビの `C` は1.5秒後、定義済み・未定義の絵文字後の `C` は各0.6秒後に開始する | |
| E17 | E16を、ルビ・絵文字を残す設定と両方オフの設定で出力する | 各 `C` の開始時刻は一致し、SRT本文だけがルビ読み・絵文字表記の有無に応じて変化する | |
