# SRTrack Object for AviUtl2

SRTrack Object は、レンダリング済み動画に対応する SRT の参照と時間変換設定を保持するカスタムオブジェクトです。SRTrack Exporter が読み取る字幕ソースとして使います。必要なら、編集画面だけで現在の SRT 字幕を確認する補助プレビューを表示できます。

## インストール

次の2ファイルをコピーして AviUtl2 を再起動します。

- `SRTrack Object.obj2` → `C:\ProgramData\aviutl2\Script\SRTrack\SRTrack Object.obj2`
- `SRTrackPreview.mod2` → `C:\ProgramData\aviutl2\Script\SRTrack\SRTrackPreview.mod2`

`SRTrackPreview.mod2` は、Unicode を含む SRT パスを読み込む編集用プレビューの補助モジュールです。Exporter を使わない場合も、プレビューを使うなら必要です。

## 設定項目

- `SRT ファイル`：対応する元 SRT を指定します。
- `再生位置`：オブジェクト開始時に参照する元 SRT の位置です。標準動画と同じ秒単位です。
- `再生範囲終端`：参照する元 SRT 範囲の終端です。Importer は対応動画と同一のフレーム境界終端を設定します。
- `動画全長`：Importer が設定する元動画の基準長です。現行版では `再生範囲終端` と同じ値で、将来のループにだけ使います。
- `再生速度`：元 SRT の時間の進み方です。標準動画と同じ百分率で、`100` は等速、`200` は2倍速です。
- `字幕プレビュー`：編集画面で SRT 由来の現在字幕を表示します。既定ではオンです。ファイル出力中は常に表示しないため、書き出した動画には反映されません。

`再生位置` と `再生範囲終端` は別の設定項目として表示される。標準動画の二値 UI と完全に同じ外観ではないが、単位と初期値は標準動画に合わせる。

## 編集用字幕プレビュー

プレビューは、`再生位置 + (再生速度 ÷ 100) × オブジェクト内時刻` で求めた SRT 元時刻に表示中の字幕を、SRTrack Object 単体で表示します。位置は通常のオブジェクト設定で調整できます。

これは編集時の確認専用です。SRTrack Exporter による標準テキスト・セリフ準備との中断、結合、オフセットの結果とは一致しない場合があります。プレビューをオンにしても、ファイル出力中は空画像にするため動画へ焼き込まれません。

SRT は初回表示時に読み込んでキャッシュします。外部で同じ SRT を編集した場合は、AviUtl2 の「キャッシュを破棄」を実行して再読み込みしてください。

SRT を Lua 側で読めない、SRT ファイルが未指定、再生速度が不正、または有効な字幕を解析できない場合は、編集画面に赤字の診断を表示します。これは確認用であり、ファイル出力には含まれません。

`再生位置`、`再生範囲終端`、`動画全長`、`再生速度`は、対応する動画との同期を前提に Importer が初期設定する値です。AviUtl2 上では手動変更できますが、動画との対応が崩れ、字幕出力や将来のループ結果が正しくなくなる可能性があります。手動変更は非推奨です。変更を強制的に禁止したり、自動で元に戻したりはしません。

手動変更されたかどうかを記録・判定することはありません。移動・分割・伸縮への追従自体は未実装です。将来は、グループ内の標準動画で本体が更新した `P`・`E`・再生速度を Object へ反映する方式を検討しています。ただし、取込処理と継続同期を同じプラグイン単位に置く場合の名称・責務を見直すまで、この実装は保留です。

SRTrack Importer は、GCMZDrops2 の公開ハンドラースクリプト API を通じて、同名 SRT を参照する Object を対応動画とグループ化して追加し、動画と同一のフレーム境界終端を `再生範囲終端` と `動画全長` に初期設定します。分割・伸縮後に標準動画の更新結果を Object へ反映する継続同期は、コンポーネントの名称・責務を再定義するまで未実装です。

## 今後の目標：動画と同期するループ

SRT の最終字幕時刻は元動画の長さではないため、SRT 単体では標準動画のループ範囲を再現できません。動画オブジェクトとの対応づけ・同期機構で動画側の再生範囲を取得できるようになった後に対応します。
