# SubtitleExport for AviUtl2

AviUtl2 の標準テキストや PSDToolKit の「セリフ準備」から、タイムスタンプ付きの SRT 字幕を出力する汎用プラグインの試作版です。初期の出力先として YouTube Studio を想定しています。

**開発中**：AviUtl2 2.1.13 を対象としています。2026年11月7日付の公式 SDK のヘッダーを使ってビルドしていますが、2.1.13 上での全機能の動作と互換性は未検証です。テスト用プロジェクトで使用し、出力した字幕を確認してください。

## 主な機能

- 現在のシーン全体、または番号・名前を指定した複数レイヤーから取得。
- 標準テキストと PSDToolKit セリフ準備を個別に選択。
- 字幕を次の字幕の開始まで表示し、設定した長さ以下の短い字幕を結合。
- オフセットによる時刻の一括調整と前回設定の保存。

## 対応環境・依存関係

- Windows x64 / AviUtl ExEdit2：対象 2.1.13、互換性は要検証。
- PSDToolKit はセリフ準備を取得する場合のみ必要。PSDToolKit 本体は同梱しません。
- ソースからのビルドには Windows SDK と MSVC の C++ 開発環境が必要です。使用する AviUtl2 SDK のヘッダーは同梱しています。

## インストールと使用

ビルドで得た `SubtitleExport.aux2` を、AviUtl2 のデータフォルダ内の `Plugin` フォルダへ配置し、AviUtl2 を再起動します。通常の場所は `C:\ProgramData\aviutl2\Plugin` です。データフォルダを別の場所に設定している場合はそちらを使用してください。

「ファイル」→「エクスポート」→「SRT字幕出力（試作版）」から実行します。レイヤー名は1行に1件入力します。カンマや空白は名前の一部です。Enter キーはレイヤー名欄では改行に使い、設定から先へ進むには「次へ」を押します。

## 設定と削除

設定画面で「次へ」を押すと、現在の Windows ユーザーのレジストリ `HKEY_CURRENT_USER\Software\SubtitleExportAviUtl2` に前回設定を保存します。保存できない場合は警告します。プラグインを削除するには AviUtl2 終了後に `.aux2` を削除してください。保存設定も不要な場合は、このレジストリキーを手動で削除できます。

## ビルド

Visual Studio の x64 Native Tools Command Prompt で次を実行します。

```bat
build.cmd
```

ビルド後に単体テストも実行します。生成した `.aux2` 等は Git 管理の対象外です。配布用バイナリを作る場合は、使用する MSVC ランタイムのライセンス・依存関係を別途確認してください。

## 現在の制約

- 制御文字の除去・ルビ・絵文字の変換は仕様検討済みですが、まだ実装されていません。制御文字や空行が含まれると警告したうえで原文を出力します。
- 表示速度・中間点・非表示・シーン参照・スクリプト生成文字列などの再現は保証していません。
- 動画を書き出した範囲は自動検出しません。先頭にオープニングを追加した場合は、その長さを正のオフセットとして入力できます。
- 前回設定の再起動後の復元、および YouTube Studio への取り込みは未検証です。

詳細は [仕様書](docs/specification.md) と [SDKの利用方針](docs/SDK_POLICY.md) を参照してください。
