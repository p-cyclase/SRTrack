# AviUtl2 字幕出力プラグイン 仕様書（案）

版：0.7／2026-11-11

状態：試作版。第4節の対象選択・設定保存と第7節の字幕切り替え・結合処理を実装。第7.3節の制御文字処理は設計方針であり、現行版には未実装。時刻・結合・入力処理の単体テストは実施済み。今回の版の AviUtl2 上での操作、設定復元、YouTube Studio への取り込みは未検証。

## 1. 目的

AviUtl2 のタイムライン上の文章と表示時間を取得し、動画プラットフォームなどで利用できる字幕データとして出力する。標準のテキストオブジェクトを基本の読み取り対象とする。

最初は YouTube Studio での利用を目指し、SRT 形式で出力する。将来的にはニコニコ動画など、他の動画プラットフォームや字幕形式への対応を検討する。各サービスの対応形式や受け渡し方法は、対応時に確認して決定する。プラグイン自体はアップロードを行わない。

## 2. 対象環境

- AviUtl ExEdit2 2.1.13 を対象に開発・検証する。別バージョンは互換性を確認したうえで対応する。
- 標準テキストの利用に PSDToolKit は必要としない。追加の読み取り対象として PSDToolKit for AviUtl2 の「セリフ準備@PSDToolKit」に対応する。PSDToolKit の対応バージョンは実機検証後に明記する。
- Windows 向け汎用プラグイン（.aux2）を想定する。SDK の 2.1.13 対応範囲は実装前に確認する。

## 3. 対象とする情報

現在編集中のシーンの指定レイヤーに配置された、標準の「テキスト」オブジェクトを基本の読み取り対象とする。加えて、PSDToolKit の「セリフ準備@PSDToolKit」にも対応する。

1. 標準の「テキスト」オブジェクトの文字列。
2. PSDToolKit の「セリフ準備@PSDToolKit」のテキスト欄。

各オブジェクトの開始・終了位置と文字列を取得する。セリフ準備は、字幕表示用オブジェクトを経由して文字列を推測せず、セリフ準備から取得する。両方が同じプロジェクトやレイヤーに混在しても処理する。対象外のオブジェクトは無視する。

字幕の読み取り・時刻の整理と、出力形式への変換は分けて考える。これにより、別の読み取り対象や出力形式の追加を検討しやすくする。これは設計方針であり、現時点で他形式に対応済みであることを意味しない。

空文字・空白のみのテキストは出力しない。元の改行は維持する。入力された文章そのものを自動で校正・翻訳しない。

## 4. 操作案

1. AviUtl2 で対象プロジェクトとシーンを開く。
2. プラグインの字幕出力メニューを選ぶ。
3. 対象範囲として、現在編集中の「シーン全体」または「レイヤーを指定」を選ぶ。
4. レイヤーを指定する場合は、番号とレイヤー名を入力する。番号は `3, 5, 8-10` のように指定し、画面表示と同じ 1 始まりとする。名前は1行につき1件入力する。
5. 対象オブジェクトとして、標準テキストとセリフ準備をそれぞれ選択する。チェックボックス形式を想定し、少なくとも一方を選択する。
6. 必要に応じて「オフセット（秒）」を入力する。初期値は `0`。
7. 短い字幕を結合する閾値と、末尾の短い字幕の最小表示時間を秒単位で指定する。初期値はそれぞれ0秒、1秒。
8. 保存先とファイル名を指定し、SRT を出力する。
9. YouTube Studio の字幕画面から、タイミング付きファイルとしてアップロードする。

### 4.1 対象レイヤーの指定

- 「シーン全体」は、プロジェクト内の全シーンではなく、現在編集中のシーンの全レイヤーを意味する。
- 「レイヤーを指定」では、番号と名前を別々の入力欄に指定する。名前欄は改行区切りとし、カンマと空白は名前の一部として扱う。ユーザー環境で、カンマと空白をレイヤー名に設定できることを確認済み。
- 名前欄の各行を1つのレイヤー名として扱い、名前中および先頭・末尾の空白も保持する。空行は指定として扱わない。
- 検索は完全一致を基本案とし、同名レイヤーが複数ある場合はすべて対象とする。番号と名前を両方指定した場合は、どちらかに一致するレイヤーを対象とし、重複して一致したレイヤーは一度だけ処理する。指定した名前が一致しない場合は通知する。詳細な表示や確認方法は未定。
- レイヤーの追加・移動によって番号が変わっても再利用できるよう、レイヤー名は番号に置き換えず、指定した文字列を保存する。

### 4.2 設定の保存

- 対象範囲、レイヤー番号・名前の指定、対象オブジェクト、オフセット、結合閾値、末尾の最小表示時間を、設定画面で「次へ」を押した時に Windows のユーザー別設定に保存し、次回起動時に復元する。設定保存に失敗した場合は通知する。字幕の保存ダイアログをキャンセルしても入力した設定は保存される。
- 名前を付けた複数の設定プリセットの保存・呼び出しは将来の実装目標とする。
- 制御文字、ルビ、絵文字、スクリプトの各処理設定についても、実装後は前回設定の自動保存・復元の対象とする。
- 設定値が取得できない場合は該当項目の初期値を用いる。復元した値の入力検証は出力時に行う。

不正な入力は保存前に内容を表示し、修正できるようにする。保存のキャンセルでは字幕ファイルを書き込まない。既存ファイルへの上書きは保存ダイアログで確認する。

## 5. 出力ファイル（初期対応：YouTube向けSRT）

- 形式：SubRip（.srt）、番号・開始時刻・終了時刻・字幕本文を持つ基本形式。
- 文字コード：UTF-8。制御文字を除去する設定では対応する装飾用の制御文字を出力しない。保持する設定では記述を残す。YouTube の SRT では装飾として認識されない点に注意する。
- 時刻表記：`HH:MM:SS,mmm`。字幕番号は 1 から連番。
- フォント、色、座標、縁取りなどの見た目は引き継がない。
- 字幕は時間順に出力する。最初の字幕から最後の字幕の終了まで、原則として字幕の間に空白を設けない。
- ニコニコ動画など他のプラットフォーム向けの形式や操作方法は将来の検討対象とし、SRT をそのまま取り込めるとは仮定しない。

```srt
1
00:00:01,000 --> 00:00:03,000
第一章

2
00:00:03,000 --> 00:00:04,000
はじめまして。
```

## 6. 時刻の決定

- 基本は現在のシーン先頭を 00:00:00,000 とし、オブジェクトのフレーム位置とシーンのフレームレートから計算する。
- 端数を含むフレームレートにも対応するため、分子・分母を保持して計算し、最後にミリ秒単位へ四捨五入する。
- 内部では開始を含み終了を含まない区間として扱う。SDK が返す終了フレームを含む場合は次のフレーム境界を終了時刻とする。SDK の実際の端点の定義は検証する。
- 1 フレームのオブジェクトも読み取り対象とする。字幕の終了時刻は、次の字幕の開始位置と第7節の結合ルールに従う。
- 基本の出力範囲はシーン全体。動画の書き出し範囲は自動検出しない。動画がシーン途中から始まる場合の補正や、動画の先頭にオープニングを追加した場合の補正には、手動のオフセットを使う。

### オフセット

- 秒単位の数値を指定し、字幕全体の開始・終了時刻に加算する。正の値は遅く、負の値は早くする。初期値は `0`。
- 小数点以下は最大3桁。例えば `5.250` は5.25秒遅らせ、`-1.5` は1.5秒早める。
- オフセット適用後、開始が0秒より前、終了が0秒より後の字幕は開始時刻を0秒にする。終了が0秒以前の字幕は出力しない。全字幕が除外される場合は保存せず通知する。
- 出力完了時に、開始前となったため除外した字幕ブロックの件数を表示する。

## 7. 字幕の切り替えと短い字幕の結合

### 7.1 字幕の区間を決める

1. 対象オブジェクトから文章と開始・終了位置を取得し、開始時刻順に並べる。同じ時刻はレイヤー番号の小さい順に並べる。
2. 最後以外の字幕は、元のオブジェクトの終了時刻にかかわらず、次の字幕の開始時刻で終了する。元のオブジェクトの表示が先に終わっても字幕を次の開始まで表示する。
3. 最後の字幕だけは、元のオブジェクトの終了フレームの次のフレーム境界を終了時刻とする。
4. 同時刻に複数の字幕が始まる場合、順番に区間を決めるため、内部的に長さ0秒の字幕が生じる。後続の結合処理で扱い、最終的な SRT に0秒の字幕を出力しない。

例：章タイトル A が 0〜10 秒、B が 2〜3 秒、C が 5〜6 秒に配置されている場合、結合前の字幕は次のようになる。

| 時間 | 字幕 |
| --- | --- |
| 0〜2 秒 | A |
| 2〜5 秒 | B |
| 5〜6 秒 | C |

A は B と重なるたびに繰り返さない。B と C の元オブジェクトの間に空白があっても、その間は B を表示する。最初の字幕の開始前と、最後の字幕の終了後には字幕を生成しない。

### 7.2 短い字幕の結合

- 表示時間が指定した閾値**以下**の字幕は、次の字幕に結合する。閾値は0秒以上、初期値は0秒とし、0秒を指定した場合も0秒字幕を結合対象とする。秒単位で小数点以下3桁まで入力できる。
- 前から順に処理し、結合後の表示時間も閾値以下なら次の字幕へさらに結合する。文章は処理順に改行でつなぎ、元の改行も維持する。別オブジェクトの同一文章を自動削除しない。
- 結合後の開始は最初の字幕の開始時刻、終了は最後に結合した字幕の終了時刻とする。結合対象の間に空白がある場合も結合し、その間も字幕を表示する。
- 次の字幕がない末尾の字幕が閾値以下の場合は、別途指定する正の「末尾の最小表示時間」まで延ばす。既にその時間以上なら短縮しない。初期値は1秒とし、秒単位で小数点以下3桁まで入力できる。
- 切り替えと結合・末尾の延長を行った後にオフセットと0秒を基準にした切り詰め・除外を適用する。最終的に出力する字幕は開始より終了が後となること。

### 7.3 制御文字の処理方針（変更予定・未実装）

字幕として読み取った文字列を出力する際、通常の制御文字、ルビ、絵文字、スクリプトをそれぞれ設定に従って処理する。各項目は独立して選択できるようにする。設定画面の形式と初期値は未定。

| 対象 | 選択肢 | 処理方針 |
| --- | --- | --- |
| 通常の制御文字 | 除去／保持 | 除去時は、認識できる色・サイズ・フォント・位置などの制御文字を取り除き、本文を残す。保持時は原文の記述を残す。 |
| ルビ | 親文字のみ／親文字＋読み／保持 | 例えば `</>漢字<!>かんじ</>` を、それぞれ `漢字`、`漢字（かんじ）`、元の記述として出力する。 |
| 絵文字 | 除去／名前を括弧付きで残す／保持 | 例えば `<&ハート>` を、それぞれ空文字、`（ハート）`、元の記述として出力する。括弧付きでは画像ではなく制御文字内の名前を使う。 |
| スクリプト | 除去／保持 | `<? ... ?>` および `<?= ... ?>` の記述を、それぞれ全体ごと除去するか原文のまま残す。実行して生成された文字列の取得・再現には対応しない。 |

- 通常の制御文字は、公式のテキスト機能の説明と実データを参考に対象構文を特定する。一般的な山括弧の文章をまとめて削除せず、認識できる構文に限定して処理する。使用するパターンや対応範囲の詳細は実装時に検証する。
- 待機・表示速度・表示クリアの制御文字を除去しても、それらによる表示の変化やタイミングは再現しない。通常の装飾除去と区別が必要な場合の通知方法は検討する。
- コメントは表示されない内容として、通常の制御文字を除去する場合にコメント全体を除去し、保持する場合は原文を残す。複数行を含むコメントも対象とする。
- スクリプトを検出した場合は、除去・保持のどちらでも、生成文字が再現されないことを通知する。検出箇所の示し方は未定。検出不能・解釈不能な記述を勝手に削除せず通知する。
- ルビやコメント内の他の制御文字、複数行、タグに似た通常文字列、構文が不完全な場合の処理を検証する。正規表現の利用を含め、文字列の区切りや構造を考慮した処理方法は実装時に決める。
- 変換後の空文字、連続する空行のSRT上の扱いは別途検討する。元のテキストの空白のみの判定は優先度を低くして保留する。

## 8. エラーと結果表示

- プロジェクトまたはシーンが利用できない場合、読み取り不可の場合、不正なレイヤー指定、保存失敗などは理由を表示する。
- 対象字幕が 0 件の場合はその旨を表示し、空のファイルは作成しない。
- 取得できない対象や解釈できないデータがある場合は、黙って欠落させず、対象位置と理由を可能な限り通知する。部分出力の可否は実装時に決める。
- 出力成功時は保存先、取得対象数、出力した字幕ブロック数、および警告件数を表示する。
- 元のプロジェクトやオブジェクトを変更しない。

## 9. 初期版の制約・要検証事項

- 制御文字の除去・保持やルビ・絵文字の変換は第7.3節の方針として整理済みで未実装。文字単位の表示やスクリプトによる文字列生成は再現対象外とし、対応範囲と通知方法を実データで検証する。
- セリフ準備の設定値の取得方法、文字列の保存形式、改行・特殊文字、各バージョンの互換性を検証する。
- 中間点や分割、非表示・無効化、グループ・シーン参照、音声の再生位置変更がある場合の表示時間と抽出範囲は実機で検証し、未対応のものは明記する。
- 結合閾値と末尾の最小表示時間の初期値・設定範囲は、実際の使用感を踏まえて見直す。元の空白区間にも字幕を表示するため、意図的に字幕を消す機能は別途検討する。
- プラグインは音声認識や自動翻訳、動画への焼き込み、YouTubeへの自動アップロードを行わない。

## 10. 受け入れ確認

1. PSDToolKit の有無にかかわらず、指定した複数レイヤーの標準テキストを読み取れる。標準テキストとセリフ準備が混在する場合も、それぞれの文章が出力される。
2. 指定外レイヤーと対象外オブジェクトは出力されない。
3. 日本語、改行、特殊文字を含む例で文字化けしない。
4. 次の字幕が始まるまで前の字幕を表示し、最後の字幕はオブジェクトの終了位置を使う。長時間の章タイトルを後続の字幕ごとに繰り返さない。
5. 30 fps と分数フレームレートで、長時間の出力でも累積的な時刻ずれが生じない。
6. 生成した SRT を YouTube Studio にアップロードし、字幕が想定どおり表示されることを確認する。
7. エラーやキャンセル時に元のプロジェクトを変更しない。
8. 正・負・ゼロのオフセット、小数秒、0秒をまたぐ字幕、すべて0秒以前になる場合について、出力時刻と通知を確認する。これらの計算は単体テスト済みで、画面操作と実機での結果は要確認。
9. 同時刻の字幕が閾値0秒で結合され、短い字幕の連続も順に結合される。結合時は文章と順序が保持され、出力に0秒の字幕が残らない。
10. 次の字幕のない末尾の短い字幕が指定した最小表示時間を確保し、元から長い場合に短縮されない。オフセット適用後の0秒をまたぐ字幕・全字幕が範囲外になる場合も確認する。
11. 「シーン全体」と「レイヤーを指定」を切り替えられ、番号と名前の指定を併用しても重複出力しない。レイヤー名のカンマ・空白を保持し、同名レイヤーや一致しない名前を想定どおり扱う。
12. 標準テキストとセリフ準備の選択を個別に切り替えられ、両方未選択の場合は出力できない。
13. 前回設定が再起動後にも復元され、レイヤー名を変更せず番号のみが変わった別プロジェクトでも名前指定が再利用できる。
14. 制御文字を除去／保持でき、通常の山括弧を含む文章を誤って削除しない。ルビ・絵文字の各選択肢が期待する文字列になり、設定を独立して変更できる。
15. スクリプトの除去／保持が選択どおりで、いずれの場合も生成文字が再現されないことを通知する。複数行のコメント・スクリプト、制御文字の組み合わせ、不完全な構文も確認する。
