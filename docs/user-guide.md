# SRTrack ユーザーガイド

この文書は、SRTrack の機能と設定を用途別に説明する操作リファレンスです。必要な章だけを読めます。標準テキストを SRT に出力するだけなら、まず [Exporter](#1-exporter) を読んでください。動画と SRT を対応づける Object や、ドロップでの自動配置は任意の機能です。

導入方法はリポジトリ直下の [README](../README.md)、既知の制約と今後の予定は [ロードマップ](roadmap.md) を参照してください。

## 1. Exporter

SRTrack Exporter は、タイムライン上の字幕を集めて SRT ファイルへ出力します。標準テキストだけでも利用できます。`SRTrack Object`、セリフ準備（PSDToolkit）を使う場合は、同じ出力に含めることもできます。

### 1.1 出力手順

1. SRTrack Exporter を開きます。
2. `出力対象` と `字幕の整形` を必要に応じて設定します。
3. 右下の `エクスポート…` を選びます。
4. Windows の保存ダイアログで、ファイル名と保存先を指定します。

Exporter の画面にはキャンセルボタンがありません。画面右上の閉じるボタン、または保存ダイアログのキャンセルで中止できます。

### 1.2 出力対象

`出力対象` タブでは、どの字幕を出力するかを指定します。

#### 対象時間範囲

- **シーン全体**：現在のシーン全体を出力します。
- **フレーム範囲選択**：AviUtl2 のフレーム範囲選択だけを出力します。選択範囲の先頭は、出力 SRT では `00:00:00,000` になります。範囲をまたぐ字幕は、選択範囲内へ切り詰められます。

#### 対象レイヤー

- **すべてのレイヤー**：すべてのレイヤーを対象にします。
- **レイヤーを指定する**：番号または名前で対象を絞り込みます。
  - **番号**：`3, 5, 8-10` のように、番号と範囲を指定できます。
  - **名前**：完全一致するレイヤー名を、1行に1件ずつ指定できます。

番号と名前は合わせて適用します。両方に一致するレイヤーも一度だけ出力されます。

#### 対象オブジェクト

- **テキスト**：AviUtl2 の標準テキスト Object を対象にします。
- **SRTrack Object**：`SRTrack Object`、`SRTrack Object (fix)`、`SRTrack Object (txt)` の三種を対象にします。
- **セリフ準備（PSDToolkit）**：PSDToolkit のセリフ準備 Object を対象にします。

必要な種類だけをオンにできます。たとえば標準テキストだけを出力する場合は、`テキスト` だけをオンにします。

#### 出力時刻のオフセット

**オフセット（秒）** は、完成した SRT 全体を前後へ移動します。正の値は字幕を遅らせ、負の値は早めます。`0.000` は移動しません。

### 1.3 字幕の整形

`字幕の整形` タブでは、出力する字幕の長さ、同時に始まる字幕の本文順、テキスト制御文字の扱いを指定します。

#### 最小表示時間

**最小表示時間** より短い字幕は、後の字幕へ結合されます。末尾に結合先がない短い字幕だけは、この時間まで延長されます。

- 入力できる最小値：`0.500` 秒
- 初期値：`1.000` 秒

動画やシーンの終端を超えて延長された字幕も、そのまま SRT へ出力されます。

#### 同時開始時の並び順

同じ時刻に始まる短い字幕が結合される場合の本文順を選びます。

- **上のレイヤーから**：Layer 1 側から本文を並べます。
- **下のレイヤーから**：下側のレイヤーから本文を並べます。

これは字幕を捨てる優先順位ではありません。本文を結合する順序です。

#### テキストの処理

- **ルビをカッコ書きで残す**：オンなら、ルビを `漢字（かんじ）` の形で出力します。オフなら親文字だけを残します。
- **絵文字をカッコ書きで残す**：オンなら、AviUtl2 の絵文字名をカッコ書きで出力します。オフなら絵文字を削除します。
- **待機・クリアを反映**：オンなら、テキストの待機・クリア制御文字を字幕の区切りや時間へ反映します。オフなら、文字送り・待機・クリア制御文字を削除して無視します。

色、サイズ、フォント、位置などの装飾用制御文字、コメント、Lua スクリプトは常に削除されます。Lua スクリプトを実行した結果の文字列は出力しません。

### 1.4 出力結果と診断

出力が終わると、対象 Object 数、字幕数、エラー・警告数、保存先を表示します。警告やエラーがあっても、出力できる字幕は保存を続けます。

問題がある場合は、結果画面の `共通ログをコピー` を使うと、調査に役立つ診断情報をコピーできます。

## 2. SRTrack Object

SRTrack Object は、動画に対応する SRT をタイムライン上で扱うための任意機能です。Object の Preview は編集画面だけに表示され、動画を書き出すときには描画されません。

### 2.1 SRTrack Object

通常の `SRTrack Object` は、設定した SRT ファイルを保持します。Object より上側にある最も近い動画 Object の再生位置・速度・ループを参照し、字幕を時間変換します。

- Object と参照動画の間には、フィルタなどの非動画 Object を置けます。
- 上側に参照できる動画 Object がない区間は、字幕を出力しません。Preview では理由を表示します。
- `字幕プレビュー` をオフにすると、その Object だけ Preview を表示しません。

### 2.2 SRTrack Object (fix)

`SRTrack Object (fix)` は動画を参照しません。Object 自身の `再生位置` と `再生速度` を使って SRT を時間変換します。動画と独立した SRT を置きたい場合に使います。

### 2.3 SRTrack Object (txt)

`SRTrack Object (txt)` は、自由入力した `テキスト` を Object の開始から終了まで一つの字幕として出力します。補足、注釈、SRT にだけ入れたいテキストに使えます。

`字幕プレビュー` がオンなら、Object の座標に合わせて編集画面へ表示します。動画を書き出すときには描画されません。

## 3. Importer

Importer は、動画と SRT の配置を自動化する任意機能です。ほかのプラグインのファイルドロップ処理と干渉する可能性があるため、不要な場合は `SRTrack 設定` から個別にオフにできます。

### 3.1 動画と同名の SRT を読み込む

動画ファイルと同名の `.srt` を同じフォルダに置いて動画をドロップすると、動画と `SRTrack Object` をまとめて配置します。動画は上側、SRTrack Object は下側に置かれ、グループ化されます。

動画と同名の SRT がない場合は、通常の動画ドロップとして扱います。

### 3.2 SRT ファイル単体のドロップ

`.srt` ファイルだけをドロップすると、選択した Object を配置します。`SRTrack 設定` で、通常の `SRTrack Object` または `SRTrack Object (fix)` を選べます。

通常の `SRTrack Object` を選んだ場合は、上側に動画 Object を置いて使います。動画なしで使う場合は `SRTrack Object (fix)` を選びます。

### 3.3 Importer の設定

`SRTrack 設定` の `設定` タブにある `Importer` では、次を個別にオン／オフできます。

- 動画ファイルドロップ時、同名の SRT ファイルがあれば読み込む
- SRT ファイル単体のドロップを読み込む
- SRT 単体ドロップ時に作成する Object 種別

Importer の設定変更は、AviUtl2 を再起動した後のファイルドロップから反映されます。

## 4. Preview と診断ログ

`SRTrack 設定` の `Preview` では、すべての SRTrack Object の Preview をまとめて表示／非表示にできます。各 Object の `字幕プレビュー` の設定値は変更されないため、再びオンにすると元の個別設定に従って表示されます。

`診断ログ` タブでは、この起動中に記録された Importer と Exporter の診断を確認できます。`診断情報をコピー` を使うと、不具合報告へ貼り付ける情報をコピーできます。

## 5. 困ったとき

- **字幕が表示されない**：対象 Object の `字幕プレビュー` と、`SRTrack 設定` の `Preview` がオンか確認します。通常の SRTrack Object では、上側に参照できる動画 Object が必要です。
- **Importer が動かない**：`Importer` の設定を確認し、変更後は AviUtl2 を再起動します。動画と SRT のファイル名も確認してください。
- **Exporter に警告・エラーが出る**：結果画面の `共通ログをコピー` を使い、[開発・不具合報告について](../CONTRIBUTING.md) の案内に従って報告してください。

診断ログには絶対パス、SRT 本文、動画名を記録しない設計ですが、投稿前に内容を確認し、公開したくない情報は伏せてください。
