# SRTrack ユーザーガイド

この文書は、SRTrack の機能と設定を説明する操作ガイドです。
単に動画プロジェクトから SRT を出力したい場合は、まず [Exporter](#1-exporter) を読んでください。動画ファイル・SRT ファイルを連携して再出力する機能を使いたい場合は、[Object](#2-object) や [Importer](#3-importer) に目を通してください。

導入方法はリポジトリ直下の [README](../README.md)、既知の制約と今後の予定は [ロードマップ](roadmap.md) を参照してください。

## 1. Exporter

SRTrack Exporter は、AviUtl2 のプロジェクトからテキスト情報を取得し、SRT ファイルを出力する機能です。出力した SRT ファイルは、YouTube などの動画投稿サイトで字幕として使用できます。

AviUtl2 のタイムライン上では、複数のテキスト情報が別のレイヤーで同時に存在する場合があります。一方、SRT ファイルは、時間的に重複しない一列の字幕として出力されます。SRTrack Exporter は、出力対象のテキスト情報を次の機序で字幕に変換します。

1. 新しいテキスト情報が始まると、そのテキスト情報を新しい字幕として扱います。
2. 次のテキスト情報が始まると、表示中の字幕をその時点で終了し、新しい字幕を始めます。
3. 同じフレームの別レイヤーで複数のテキスト情報が始まる場合は、設定した並び順で処理します。先に処理されたテキスト情報は、いったん長さ0フレームの字幕として扱われます。
4. 最後に、最小字幕時間より短い字幕を結合・延長処理します。長さ0フレームの字幕の存在もこの処理によって解決されます。

### 1.1 出力手順

1. AviUtl2 の `ファイル` メニューから `エクスポート`、`SRTrack Exporter` の順に選びます。
2. 必要に応じて、`出力対象` と `字幕の整形` の設定を変更します。
3. 右下の `エクスポート…` を選びます。
4. 保存先を選び、ファイル名を入力して保存します。

### 1.2 設定項目について

#### 1.2.1 出力対象

`出力対象` タブでは、どのテキスト情報を SRT に出力するかを指定します。

#### 対象時間範囲

- **シーン全体**：現在のシーン全体を出力します。
- **フレーム範囲選択**：AviUtl2 のフレーム範囲選択だけを出力します。選択範囲の先頭は、出力 SRT では `00:00:00,000` になります。範囲をまたぐ字幕は、選択範囲内へ切り詰められます。

#### 対象レイヤー

- **すべてのレイヤー**：すべてのレイヤーを対象にします。
- **レイヤーを指定する**：番号または名前で対象を絞り込みます。
  - **番号**：`3, 5, 8-10` のように、番号と範囲を指定できます。
  - **名前**：完全一致するレイヤー名を、1行に1件ずつ指定できます。

番号または名前に一致したレイヤーを対象にします。両方に一致するレイヤーは重複せずに出力されます。

#### 対象オブジェクト

- **テキスト**：AviUtl2 の標準テキスト Object を対象にします。
- **SRTrack Object**：`SRTrack Object`、`SRTrack Object (fix)`、`SRTrack Object (txt)` の三種を対象にします。
- **セリフ準備（PSDToolkit）**：PSDToolkit のセリフ準備 Object を対象にします。

必要な種類だけをチェックできます。たとえば標準テキストだけを出力する場合は、`テキスト` だけをチェックします。

#### 出力時刻のオフセット

完成した SRT 全体を前後へ移動します。正の値は字幕を遅らせ、負の値は早めます。`0.000` では移動しません。

#### 1.2.2 字幕の整形

`字幕の整形` タブでは、出力する SRT 内の字幕の長さ、同時に始まる字幕の本文順、テキスト制御文字の扱いを指定します。

#### 最小字幕時間

この時間未満の字幕は、延長するか次の字幕と結合されます。結合後も短い場合は、同じ判断を繰り返します。`0.000` を指定すると、同フレームのテキストのみが結合されます。
動画やシーンの終端を超えて延長された字幕も、そのまま SRT へ出力されます。

#### 空白補間時間

この時間未満の空白は、直前の字幕を延長して埋めます。本文は結合しません。`0.000` を指定すると、補間は行われません。

動画不在区間、Object の切替・終端、フレーム範囲選択の境界をまたぐ空白は埋めません。

#### 同時開始時の並び順

同じ時刻に始まる短い字幕が結合される場合の本文順を選びます。

- **上のレイヤーから**：Layer 1 側から本文を並べます。
- **下のレイヤーから**：下側のレイヤーから本文を並べます。

#### テキストの処理

- **ルビをカッコ書きで残す**：オンなら、ルビを `漢字（かんじ）` のような形で出力します。オフなら親文字だけを残します。
- **絵文字をカッコ書きで残す**：オンなら、AviUtl2 の絵文字名をカッコ書きで出力します。オフなら絵文字を削除します。
- **待機・クリアを反映**：オンなら、待機時間、文字送り速度、表示文字数から字幕の時刻を計算し、クリア制御文字の位置で字幕を区切ります。オフなら、文字送り・待機・クリア制御文字をただ削除して無視します。

色、サイズ、フォント、位置などの装飾用制御文字、コメント、Lua スクリプトは常に削除されます。Lua スクリプトを実行した結果の文字列は出力しません。

Lua スクリプトなどで実際に表示される文字列が変化する場合は、AviUtl2 上の表示文字数をSRTrackが取得できないため、字幕の時刻がずれる可能性があります。スクリプト制御を使うテキストは、出力後の SRT を確認してください。

### 1.3 出力結果と診断

出力が終わると、対象 Object 数、字幕数、エラー・警告数、保存先が表示されます。
警告やエラーが出ている場合、一部のテキスト情報がSRTファイルに反映されていない可能性があります。
結果画面の `共通ログをコピー` を押すと、診断情報をコピーできます。バグ報告の際に添えていただけると調査に役立てることができます。

## 2. Object

Exporter で出力対象にできる SRTrack 独自の Object 群です。
編集画面では各 Object のテキスト情報を Preview 表示することができます。設定や読み込み状態に応じたメッセージが表示される場合もあります。動画を書き出すときには、これらの文字列は描画されません。
Preview は各 Object のテキスト情報を個別に表示するため、Exporter が統合・整形した最終 SRT 字幕とは一致しない場合があります。
各Objectの`字幕プレビュー` をオフにすると、Preview を表示しません。

### 2.1 SRTrack Object

動画 Object と連携することを前提とした Object です。SRTファイルのパスを設定することができます。
上側レイヤーにある最も近い動画 Object の再生位置・再生速度・ループ再生の設定を参照し、SRT ファイル内の該当区間を Exporter の出力対象として扱います。

動画 Object の再生速度に中間点がある場合は、中間点ごとに再生位置と速度を読み直し、瞬間移動であると仮定して字幕時刻を計算します。速度に連続的な変化が設定されている場合、字幕の時刻がずれる場合があります。

動画 Object でループ再生を使う場合は、 `全長` に元動画の長さを設定してください。この値を繰り返しの周期として、SRT の先頭へ戻る位置を計算します。ループ再生を使わない場合は設定不要です。

- Object と参照動画の間のレイヤには、フィルタなどの非動画 Object を置くこともできます。
- 上側に参照できる動画 Object がない区間は、Exporter では字幕がない区間として扱われます。Preview では注意メッセージが表示されますが、そのメッセージ自体は動画にも SRT 字幕にも出力されません。

### 2.2 SRTrack Object (fix)

`SRTrack Object (fix)` は独自に再生位置・再生速度・ループ再生・全長の設定を持ち、動画オブジェクトを参照しません。それ以外の機能はSRTrack Objectと同等です。ループ再生を使う場合、`全長` は繰り返しの周期を表します。
現時点で単独の用途は想定されていません。将来的に、SRTrack ObjectをSRTrack Object(fix)に「固定」する機能の構想があります。

### 2.3 SRTrack Object (txt)

`SRTrack Object (txt)` は、自由入力ができる `テキスト`欄を持つ Object です。入力したテキストは、Object の開始から終了までテキスト情報として扱われます。
補足、注釈、SRT にだけ入れたいテキスト情報に使えます。将来的に、SRTrack Objectを複数のSRTrack Object(txt)に「分解」する機能の構想があります。

## 3. Importer

Importer は、動画ファイルや SRT ファイルを AviUtl2 へドロップしたときに、SRTrack Object の配置を補助する機能です。

Importer は GCMZDrops2 を前提プラグインとして利用します。ファイルドロップを扱うため、ほかのプラグインと干渉する可能性が高い機能です。そのため、各機能は SRTrack 設定から個別にオン／オフできるようにしてあります。

### 3.1 動画と同名の SRT を読み込む

動画ファイルがタイムラインにドロップされた時、同じフォルダ内に動画ファイルと同名の `.srt` ファイルを検出した場合、動画オブジェクトと `SRTrack Object` をまとめて配置します。SRTrack Object は動画オブジェクトのひとつ下に置かれ、グループ化されます。また、SRTrack Object の `全長` に動画ファイルの長さが自動で設定されます。

動画と同名の SRT ファイルがない場合、SRTrack は Object を追加しません。その後の動画ファイルの読込可否や処理は、AviUtl2 と他の導入済みプラグインの設定に従います。

### 3.2 SRT ファイル単体のドロップ

`.srt` ファイルだけをドロップした場合も、SRTrack Object を配置できます。`SRTrack 設定` で、作成する Object を通常の `SRTrack Object` または `SRTrack Object (fix)` から選べます。

通常の `SRTrack Object` を選んだ場合は、上側に動画 Object を置いて使います。動画なしで使う場合は `SRTrack Object (fix)` を選びます。

設定値の詳細は、[設定パネル](#4-設定パネル)を確認してください。

## 4. 設定パネル

`SRTrack 設定` は、SRTrack の動作設定と診断ログを確認するためのパネルです。`設定` タブには `Importer` と `Preview`、`診断ログ` タブには起動中の記録を表示します。

### 4.1 Importer

`Importer` では、次を設定できます。

- 動画ファイルドロップ時、同名の SRT ファイルがあれば読み込む
- SRT ファイル単体のドロップを読み込む
- SRT 単体ドロップ時に作成する Object 種別

他のプラグインのファイルドロップ処理と組み合わせる場合など、Importer を使わない経路は個別にオフにできます。変更は、AviUtl2 を再起動した後のファイルドロップから反映されます。

### 4.2 Preview

`SRTrack 設定` の `Preview` では、すべての SRTrack Object の Preview をまとめて表示／非表示にできます。各 Object の `字幕プレビュー` の設定値は変更されないため、再びオンにすると元の個別設定に従って表示されます。

通常の Preview には `[SRTrack] ` が付きます。これは編集用の補助表示であり、動画や SRT ファイルには出力されません。Preview で問題を表示する場合は、`注意`、`設定`、`読み込みに失敗` のいずれかを表示します。通常の `SRTrack Object` で上側に動画 Object がない場合は `注意` であり、Exporter では字幕を出力しない区間として扱われます。

### 4.3 診断ログ

`診断ログ` タブでは、この起動中に記録された Importer と Exporter の診断を確認できます。`診断情報をコピー` を使うと、不具合報告へ貼り付ける情報をコピーできます。

診断ログには絶対パス、SRT 本文、動画名を記録しない設計ですが、不具合報告へ投稿する前に内容を確認し、公開したくない情報は伏せてください。

## 5. 困ったとき

- **Preview が表示されない**：対象 Object の `字幕プレビュー` と、`SRTrack 設定` の `Preview` がオンか確認します。
- **動画なしで SRT を使いたい**：動画を参照しない `SRTrack Object (fix)` を使います。SRT ファイル単体をドロップするときは、`SRTrack 設定` の Importer で作成する Object 種別を選べます。
- **ループ再生で字幕が出ない**：Object の `全長` が 0 になっていないか確認します。ループ再生では、`全長` を繰り返しの周期として使います。
- **Exporter の結果に期待したテキストがない**：Exporter の対象レイヤーと対象 Object を確認します。通常の `SRTrack Object` は、上側に参照可能な動画 Object がない区間を出力しません。
- **Importer が動かない、または意図しない動作をする**：SRTrack の不具合のほか、ほかのインポーター系プラグインとの干渉が原因である可能性があります。切り分けとして、`SRTrack 設定` の Importer をオフにしてから AviUtl2 を再起動すると、SRTrack による取込処理を無効にできます。改善しない場合や不具合を報告する場合は、導入しているほかのインポーター系プラグインと、診断ログを添えてください。
- **Exporter に警告・エラーが出る**：結果画面の `共通ログをコピー`、または `SRTrack 設定` の診断ログにある `診断情報をコピー` を使い、[開発・不具合報告について](../CONTRIBUTING.md) の案内に従って報告してください。
