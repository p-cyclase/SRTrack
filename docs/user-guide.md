# SRTrack ユーザーガイド

この文書は、SRTrack を AviUtl2 で使うための操作案内です。導入方法はリポジトリ直下の [README](../README.md) を、現在の仕様は [仕様書](spec/README.md) を参照してください。

## 1. 基本的な使いかた

1. 動画を書き出すとき、対応する SRT ファイルも保存します。
2. 後のプロジェクトでは、動画と SRT を対応づけて配置します。
3. 動画を結合・切り抜き・速度変更して編集します。
4. SRTrack Exporter で、編集結果に対応する SRT を出力します。

編集画面で表示する Preview は確認用です。動画を書き出すとき、Preview の文字は動画へ描画されません。

## 2. Exporter で SRT を出力する

SRTrack Exporter を開き、`出力対象` と `字幕の整形` を設定して、右下の `エクスポート…` を選びます。保存先は、その後に表示される Windows の保存ダイアログで指定します。

### 出力対象

- **対象時間範囲**：`シーン全体` または `フレーム範囲選択` を選びます。フレーム範囲選択では、選択範囲の先頭が出力 SRT の `00:00:00,000` になります。
- **対象レイヤー**：すべてのレイヤーを対象にするか、レイヤー番号・レイヤー名で絞り込みます。番号と名前の両方に一致するレイヤーも、一度だけ出力されます。
- **対象オブジェクト**：`テキスト`、`SRTrack Object`、`セリフ準備（PSDToolkit）` を個別に選べます。`SRTrack Object` を選ぶと、通常・`(fix)`・`(txt)` の三種が対象になります。
- **出力時刻のオフセット**：完成した SRT 全体を前後へ移動します。正の値は遅らせ、負の値は早めます。

### 字幕の整形

- **最小表示時間**：この値より短い字幕は、後の字幕へ結合します。末尾の字幕だけは、この値まで延長します。入力できる最小値は 0.500 秒、初期値は 1.000 秒です。
- **ルビをカッコ書きで残す**：オンなら、ルビを `漢字（かんじ）` の形で出力します。
- **絵文字をカッコ書きで残す**：オンなら、AviUtl2 の絵文字名をカッコ書きで出力します。
- **待機・クリアを反映**：オンなら、テキストの待機・クリア制御文字を字幕の区切りや時間へ反映します。
- **同時開始時の並び順**：同時に始まる短い字幕が結合される場合の本文順を、上のレイヤーから／下のレイヤーから選びます。

装飾用の制御文字、コメント、Lua スクリプトは SRT 出力時に削除されます。

## 3. SRTrack Object を使う

### SRTrack Object

動画に対応する SRT 用の基本 Object です。Object より上側にある最も近い動画 Object を参照し、その動画の再生位置・速度・ループに合わせて SRT を変換します。動画と Object の間には、フィルタなどの非動画 Object を置けます。

動画を Importer で取り込む場合は、動画と同名の `.srt` を同じフォルダに置いてから動画をドロップすると、動画と SRTrack Object がまとめて配置されます。

### SRTrack Object (fix)

動画を参照せず、Object 自身の再生位置と速度で SRT を変換します。動画とは独立した SRT を置きたい場合に使います。

### SRTrack Object (txt)

自由入力したテキストを、Object の開始から終了まで一つの字幕として出力します。補足、注釈、SRT にだけ入れたいテキストに使えます。

## 4. Importer

`SRTrack 設定` の `設定` タブにある `Importer` では、次を設定できます。

- 動画ファイルをドロップしたとき、同名の SRT ファイルを読み込む。
- SRT ファイル単体のドロップを読み込む。
- SRT 単体ドロップ時に作成する Object を、通常の `SRTrack Object` または `SRTrack Object (fix)` から選ぶ。

Importer の設定変更は、AviUtl2 を再起動した後のファイルドロップから反映されます。

## 5. Preview と診断ログ

`SRTrack 設定` の `Preview` では、すべての SRTrack Object の Preview をまとめて表示／非表示にできます。各 Object の個別設定は変更されないため、再びオンにすると元の個別設定に従って表示されます。

`診断ログ` タブでは、この起動中に記録された Importer と Exporter の診断を確認できます。`診断情報をコピー` を使うと、不具合報告へ貼り付ける情報をコピーできます。

## 6. 困ったとき

- **字幕が表示されない**：対象 Object の `字幕プレビュー` と、`SRTrack 設定` の `Preview` がオンか確認します。通常の SRTrack Object では、上側に参照できる動画 Object が必要です。
- **Importer が動かない**：`Importer` の設定を確認し、変更後は AviUtl2 を再起動します。動画と SRT のファイル名も確認してください。
- **Exporter に警告・エラーが出る**：結果画面の `共通ログをコピー` を使い、[不具合報告と貢献](../CONTRIBUTING.md) の案内に従って報告してください。

診断ログには絶対パス、SRT 本文、動画名を記録しない設計ですが、投稿前に内容を確認し、公開したくない情報は伏せてください。
