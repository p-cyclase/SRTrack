SRTrack
========

この ZIP は AviUtl2 用の SRTrack 配布物です。

導入方法
--------
1. AviUtl2 を終了します。
2. ZIP を任意の場所へ解凍します。
3. 解凍してできたフォルダ内の Pluginフォルダと Scriptフォルダを、AviUtl2 のデータフォルダへコピーします。既存ファイルの置換を確認された場合は置き換えます。
4. AviUtl2 を起動します。初回はプラグインやスクリプトを信頼するか確認されるため、内容を確認したうえで SRTrack の読み込みを信頼します。

この readme.txt は読むだけのファイルです。AviUtl2 のデータフォルダへコピーする必要はありません。

前提プラグイン
--------------
SRTrack は AviUtl2 / ExEdit2 2.1.13 で動作確認しています。
利用前に、次のプラグインを導入してください。いずれも SRTrack には同梱しません。

- GCMZDrops2
- L-SMASH Works

詳しい使いかた、更新情報、不具合報告は、次の配布元リポジトリを参照してください。
https://github.com/p-cyclase/SRTrack
