SRTrack
========

この ZIP は AviUtl2 用の SRTrack 配布物です。

導入方法
--------
1. AviUtl2 を終了します。
2. ZIP の Plugin フォルダと Script フォルダを、AviUtl2 のデータフォルダへ
   フォルダ構造を保ったまま展開します。
3. AviUtl2 を起動します。

動作確認済み環境
----------------
- Windows x64
- AviUtl2 / ExEdit2 2.1.13
- GCMZDrops2
- L-SMASH Works

詳しい使いかた、更新情報、不具合報告は配布元リポジトリを参照してください。
