# 既知の制約と今後の予定

SRTrack v0.1.0 は試験段階の初期公開版です。動画と対応する SRT を素材として扱い、動画の結合・切り抜き・分割・固定速度変更後に字幕を再出力する、という主な用途を実機で確認しています。

この文書では、現在対応していない機能、確認を続けている範囲、今後追加すると便利な機能を分けて示します。変更の履歴は [CHANGELOG.md](../CHANGELOG.md)、正確な現在仕様は [仕様書](spec/README.md) を参照してください。

## 未対応の機能・制約

現在の SRTrack は、通常の編集での動画の結合・切り抜き・分割・固定速度変更を主な対象にしています。次の編集条件には対応していません。

- 動画 Object の逆再生
- 動画 Object の時間制御による、複雑な再生時間変化
- 動画 Object に中間点がある場合の再生状態の追従（v0.1.0 では未対応。次期対応の方針は下記）
- テキスト内の Lua スクリプトによって出力される文字列の反映

これらを含む動画では、出力した字幕の時刻が編集結果と一致しない可能性があります。

これらの制約は、利用者からの要望、実現性、保守負担を踏まえて優先度を判断します。項目によっては実装しない判断になる可能性があります。

## 設計済みの次期対応

動画 Object の中間点で明示的に再生速度を切り替える編集については、対応方針を定めています。Object の開始・中間点・終了で区切った各区間の先頭速度を用いて再生位置を積算し、区間ごとに字幕時刻を近似変換します。フレーム単位での状態追跡や、区間内の複雑な速度変化の完全再現は行いません。

中間点をまたぐ字幕は、内部で前後に分割して再結合せず、開始した区間の候補として一度だけ生成します。後続候補と重なる場合は通常の字幕統合規則で終了時刻を切り詰めます。詳細は [時間変換と動画参照](spec/03-timing.md) を参照してください。

## 確認を続けていること

SRTrack は AviUtl2 / ExEdit2 2.1.13、GCMZDrops2、L-SMASH Works を導入した環境で確認しています。すべての AviUtl2 の版、入力形式、他プラグインとの組み合わせを網羅しているわけではありません。

想定と異なる動作を見つけた場合は、再現手順と診断情報を添えて [GitHub Issues](https://github.com/p-cyclase/SRTrack/issues) へ報告してください。報告方法は [開発・不具合報告について](../CONTRIBUTING.md) にまとめています。

## 今後の予定

次の機能は、現在の字幕出力に必須ではありませんが、編集を便利にする拡張として検討しています。

- `SRTrack Object` を `SRTrack Object (fix)` へ固定する変換
- SRT 内の字幕を `SRTrack Object (txt)` の個別 Object へ分割する変換
- 利用者からの報告に基づく互換性、診断、操作性の改善

実装の時期や内容を約束するものではありません。要望や優先順位についての意見も [GitHub Issues](https://github.com/p-cyclase/SRTrack/issues) で受け付けます。
