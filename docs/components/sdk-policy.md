# AviUtl2 SDKの利用方針

## 基本方針

このプラグインでは、AviUtl2との連携に必要な機能が公式のAviUtl ExEdit2 Plugin SDKに用意されている場合、原則としてSDKの定義・機能を利用する。字幕の抽出条件、字幕の結合、SRTへの変換など、SDKが提供しないプラグイン固有の処理は、このプラグイン側で実装する。

SDKを直接使わずにプラグインを作ること自体を問題視するものではない。この方針は、定義の食い違いを避け、変更時の保守や確認をしやすくするために採用する。

## 現在の構成

- AviUtl2との接続には `third_party/aviutl2-sdk/plugin2.h` を、Preview モジュールとの接続には `third_party/aviutl2-sdk/module2.h` を読み込む。以前使用していた独自の構造体定義は、公開用ソースでは置き換え済み。
- 同梱ヘッダーの出典は2026年11月7日付の公式SDK。文字コードをCP932からUTF-8に変換しており、変換前後のテキスト内容が一致することを確認済み。
- 以前の独自定義について、このSDKと主要な項目の配置を照合し、公式ヘッダーを使ったビルドと単体テストを実施済み。
- 対象環境はAviUtl2 2.1.13。SDKの日付が本体より新しいことだけでは非互換とは判断せず、使用するAPIと更新履歴を確認し、実際の動作で検証する。公式ヘッダーでビルドした版について、標準テキストからの字幕取得と SRT 出力、SRTrack Object の設定取得と SRT 出力は概略確認済みである。外部字幕準備オブジェクト、レイヤー指定、オフセット、設定保存を含む全機能と SDK 互換性は未検証であり、詳細な検証状態は [全体仕様書](../spec/README.md) を正とする。

## 更新時の扱い

1. 公式配布元からSDKを取得し、入手元と版または日付を記録する。
2. このプラグインが使う定義やAPIの変更点と、対応対象のAviUtl2で使用可能かを確認する。
3. ヘッダーを同梱・更新する場合は、SDKに付属する著作権表示とライセンス文を維持する。変換や変更を加えた場合は、その内容を明記する。
4. ビルドと単体テストを実施したうえで、対象のAviUtl2上で読み込み・対象取得・設定保存・SRT出力を確認する。ビルド成功だけでは実機互換性の確認にはならない。
5. 更新した版、確認した環境、未確認事項をREADME等に反映する。
