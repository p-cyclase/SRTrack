# Exporter

> **履歴資料**：本書の旧 SRTrack Object と Monitor に関する説明は正規仕様ではない。次期の Object 入力と時間変換は [全体仕様書](../spec/README.md) を優先する。

> Exporter は `SRTrack.aux2` 内の論理コンポーネントです。次期構成では Importer と同じ DLL に収録しますが、責務とソースは分けます。

AviUtl2 の標準テキストや対応する外部字幕準備オブジェクトから、タイムスタンプ付きの SRT 字幕を出力する汎用プラグインの試作版です。初期の出力先として YouTube Studio を想定しています。

**開発中**：AviUtl2 2.1.13 を対象としています。標準テキスト、SRTrack Object の字幕取得と SRT 出力、編集用プレビューは同バージョンで簡易確認済みです。SRTrack Object のループ出力は実装済みですが、実機検証は未完了です。外部字幕準備オブジェクト、レイヤー指定、オフセット、設定保存を含む網羅検証と SDK 互換性は未完了です。テスト用プロジェクトで使用し、出力した字幕を確認してください。

## 主な機能

- 現在のシーン全体、または番号・名前を指定した複数レイヤーから取得。
- 標準テキスト、対応する外部字幕準備オブジェクト、SRTrack Object を個別に選択。
- 字幕を次の字幕の開始まで表示し、設定した長さ以下の短い字幕を結合。
- オフセットによる時刻の一括調整と前回設定の保存。

## 対応環境・依存関係

- Windows x64 / AviUtl ExEdit2：対象 2.1.13、互換性は要検証。
- 外部字幕準備オブジェクトは対応する場合のみ必要であり、外部ツール本体は同梱しません。
- ソースからのビルドには Windows SDK と MSVC の C++ 開発環境が必要です。使用する AviUtl2 SDK のヘッダーは同梱しています。

## インストールと使用

`build.cmd` で生成した `out\Plugin\SRTrack\SRTrack.aux2` を、AviUtl2 のデータフォルダ内の `Plugin\SRTrack` フォルダへ配置し、AviUtl2 を再起動します。通常の場所は `C:\ProgramData\aviutl2\Plugin\SRTrack` です。データフォルダを別の場所に設定している場合はそちらを使用してください。

SRTrack Object の編集用字幕プレビューも使う場合、`out\Script\SRTrack\SRTrackObject.obj2` と `SRTrack.mod2` を `C:\ProgramData\aviutl2\Script\SRTrack` へ配置します。Standalone も使う場合は `SRTrackObject(Standalone).obj2` も同じ場所へ配置します。`SRTrack.mod2` は日本語を含むパスの SRT を読み込むための補助モジュールです。

「ファイル」→「エクスポート」→「SRTrack Exporter（試作版）」から実行します。レイヤー名は1行に1件入力します。カンマや空白は名前の一部です。Enter キーはレイヤー名欄では改行に使い、設定から先へ進むには「次へ」を押します。

## 設定と削除

設定画面で「次へ」を押すと、現在の Windows ユーザーのレジストリ `HKEY_CURRENT_USER\Software\SRTrack` に前回設定を保存します。保存できない場合は警告します。プラグインを削除するには AviUtl2 終了後に `.aux2` を削除してください。保存設定も不要な場合は、このレジストリキーを手動で削除できます。

## ビルド

Visual Studio の x64 Native Tools Command Prompt で次を実行します。

```bat
build.cmd
```

ビルド後に単体テストも実行します。生成した `.aux2` 等は Git 管理の対象外です。配布用バイナリを作る場合は、使用する MSVC ランタイムのライセンス・依存関係を別途確認してください。

## 現在の制約

- 標準テキストとセリフ準備では、装飾用制御文字・コメント・Lua スクリプトを削除します。ルビ・絵文字はカッコ書きへの変換を初期値として、個別にオフにできます。SRT ファイル本文は変換しません。
- 表示速度・中間点・非表示・シーン参照・スクリプト生成文字列などの再現は保証していません。
- 動画を書き出した範囲は自動検出しません。先頭にオープニングを追加した場合は、その長さを正のオフセットとして入力できます。
- 前回設定の再起動後の復元、および YouTube Studio への取り込みは未検証です。

詳細は [仕様書](exporter-specification.md) と [SDKの利用方針](sdk-policy.md) を参照してください。
