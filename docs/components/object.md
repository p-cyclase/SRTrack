# SRTrack Object

> Object の実装は `src/object/SRTrack.obj2`、プレビュー補助モジュールの実装は `src/mod2/module.cpp` に置きます。配布名は `SRTrack.obj2` と `SRTrack.mod2` です。

SRTrack Object は、レンダリング済み動画に対応する SRT の参照と時間変換設定を保持するカスタムオブジェクトです。SRTrack Exporter が読み取る字幕ソースとして使います。必要なら、編集画面だけで現在の SRT 字幕を確認する補助プレビューを表示できます。

## インストール

次の2ファイルをコピーして AviUtl2 を再起動します。

- `out\Script\SRTrack\SRTrack.obj2` → `C:\ProgramData\aviutl2\Script\SRTrack\SRTrack.obj2`
- `out\Script\SRTrack\SRTrack.mod2` → `C:\ProgramData\aviutl2\Script\SRTrack\SRTrack.mod2`

`SRTrack.mod2` は、Unicode を含む SRT パスを読み込む編集用プレビューの補助モジュールです。Exporter を使わない場合も、プレビューを使うなら必要です。

## 設定項目

- `SRT ファイル`：対応する元 SRT を指定します。
- `再生位置`：オブジェクト開始時に参照する元 SRT の位置です。標準動画と同じ秒単位です。
- `再生範囲終端`：参照する元 SRT 範囲の終端です。Importer は対応動画と同一のフレーム境界終端を設定します。
- `動画全長`：Importer が設定する元動画の基準長です。現行版では `再生範囲終端` と同じ値で、ループにだけ使います。
- `再生速度`：元 SRT の時間の進み方です。標準動画と同じ百分率で、`100` は等速、`200` は2倍速です。
- `ループ再生`：動画全長を周期として、元 SRT 時刻を先頭へ戻して繰り返します。既定ではオフです。
- `字幕プレビュー`：編集画面で SRT 由来の現在字幕を表示します。既定ではオンです。ファイル出力中は常に表示しないため、書き出した動画には反映されません。

`再生位置` と `再生範囲終端` は Lua のトラックグループとして一組に表示する。標準動画と同じく、開始・終端を並べて確認できる二値 UI とする。

現行の Lua Object 単体では、タイムライン上の Object 名を設定しない。完成時は `SRTrack.aux2` の Importer が生成した Object の名前を、対応する SRT ファイル名へ設定する。手動配置でファイル未指定の場合は標準名 `SRTrack` のままとする。

## 編集用字幕プレビュー

プレビューは、`再生位置 + (再生速度 ÷ 100) × オブジェクト内時刻` で求めた SRT 元時刻に表示中の字幕を、SRTrack Object 単体で表示します。`ループ再生` がオンなら、`動画全長` を周期としてこの時刻を先頭へ戻します。位置は通常のオブジェクト設定で調整できます。

これは編集時の確認専用です。SRTrack Exporter による標準テキスト・セリフ準備との中断、結合、オフセットの結果とは一致しない場合があります。プレビューをオンにしても、ファイル出力中は空画像にするため動画へ焼き込まれません。

SRT は初回表示時に読み込んでキャッシュします。外部で同じ SRT を編集した場合は、AviUtl2 の「キャッシュを破棄」を実行して再読み込みしてください。

SRT を Lua 側で読めない、SRT ファイルが未指定、再生速度が不正、または有効な字幕を解析できない場合は、編集画面に赤字の診断を表示します。これは確認用であり、ファイル出力には含まれません。

`再生位置`、`再生範囲終端`、`動画全長`、`再生速度`は、対応する動画との同期を前提に Importer が初期設定する値です。AviUtl2 上では手動変更できますが、動画との対応が崩れ、字幕出力や将来のループ結果が正しくなくなる可能性があります。手動変更は非推奨です。変更を強制的に禁止したり、自動で元に戻したりはしません。

手動変更されたかどうかを記録・判定することはありません。`動画同期` は Importer が生成する Object だけでオンになる管理フラグです。`SRTrack.aux2` 内の Monitor は、管理対象の標準動画で本体が更新した `P`・`E`・再生速度・ループ・ファイル参照・タイムライン範囲を Object へ反映します。Object 側の変更は動画側の値へ差し戻します。Importer は初期配置、Monitor は継続同期を担当します。移動・伸縮・分割とリネームは概略確認済みで、網羅検証は未実施です。

Importer は、GCMZDrops2 の公開ハンドラースクリプト API を通じて、同名 SRT を参照する Object を対応動画とグループ化して追加し、動画と同一のフレーム境界終端を `再生範囲終端` と `動画全長` に初期設定します。分割・伸縮後に標準動画の更新結果を Object へ反映する継続同期は Monitor の責務であり、初期実装済み・概略確認済みです。

## ループ再生

SRT の最終字幕時刻は元動画の長さではないため、ループ周期には使いません。Importer が初期化した `動画全長 D` を周期に使います。`D` が 0 以下の場合はループ再生を行わず、編集用プレビューは設定エラーを表示します。Exporter も同じ周期で SRT を繰り返し出力します。
