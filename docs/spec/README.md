# SRTrack 全体仕様書

SRTrack は、AviUtl ExEdit2 上で字幕を扱い、編集後のタイムラインに対応する SRT を出力するためのツールキットである。本仕様書は、実装済みの SRTrack Exporter と、今後実装する SRTrack Object を共通の目的に沿って整理する。

## コア・コンセプト

SRTrack は、**レンダリング済み動画を切り貼りして再編集しても、元の字幕情報を失わずに、編集後の動画に対応する SRT を再構成できるようにする**ためのツールキットである。

AviUtl2 のプロジェクト内にある標準テキストや PSDToolKit のセリフ準備には、字幕本文と正確なタイミングが残っている。SRTrack Exporter はそれらを読み取り、YouTube などで使える SRT として出力する。

しかし、一度レンダリングした動画を別のプロジェクトで連結、切り抜き、分割、速度変更すると、動画ファイル単体には字幕の元データが残らない。音声認識で字幕を作り直す方法では、元の文字列やタイミングを十分に再現できない場合がある。

そこで SRTrack Object は、ある動画と、その動画を出力した時点の SRT を対応づける。動画オブジェクトの再生開始、終了位置、速度などの時間的な挙動に同期して SRT の参照範囲を表し、SRTrack Exporter はその結果を他の字幕ソースとともに出力する。

このため、SRTrack Object は字幕を動画へ描画するためのオブジェクトでも、単に手動で SRT の時刻を調整するだけのオブジェクトでもない。**動画オブジェクトの編集結果を字幕情報へ正確に引き継ぐ、対応する動画の字幕側の相方**である。編集画面だけの補助プレビューは、この主目的を変えない。

動画との対応づけ、再生開始・終了、速度、トリミング、分割への追従は、この概念から導かれる中核要件である。仕様上の選択がある場合は、レンダリング済み動画の再編集後にも元字幕をできる限り正確に再構成できるかを最優先の判断基準とする。

この操作モデルの先例として PSDToolKit2 の「セリフ準備」を参照する。参照するのは字幕テキストや設定名ではなく、音声ファイルをタイムラインに置いたときに対応する準備オブジェクトを生成・グループ化し、移動、分割、伸縮などの編集結果を両者で同期させる考え方である。SRTrack ではこれを動画ファイルと SRTrack Object の組に適用する。

## 現在の実装状況

| 要素 | 状態 |
| --- | --- |
| SRTrack Exporter | 実装済み。標準テキストからの字幕取得と SRT 出力は AviUtl2 2.1.13 で確認済み。 |
| PSDToolKit のセリフ準備の読取り | 実装済み。実機での互換性・設定値の保存形式は未検証。 |
| SRTrack Object | SRT の参照・再生設定と、編集用の非出力字幕プレビューを実装中。AviUtl2 上での読み込み・プレビューは未検証。 |
| SRTrack Object からの出力 | SRT 解析・固定正速度での時間変換を実装中。実機検証は未実施。 |
| 字幕プレビュー | SRTrack Object 単体の編集用プレビューを実装中。Exporter 統合結果との一致は対象外。 |

## 初期版の到達点

初期版は、UTF-8 SRT を参照する非出力の読み込みオブジェクトをタイムラインに置き、固定の正の速度・ループなしの範囲で、元 SRT の区間を編集後のシーン時刻に変換して出力できることを目標とする。標準テキスト、PSDToolKit のセリフ準備、SRT 由来の字幕を混在できることを目指す。
