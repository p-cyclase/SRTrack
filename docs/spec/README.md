# SRTrack 全体仕様書

SRTrack は、AviUtl ExEdit2 上で字幕を扱い、編集後のタイムラインに対応する SRT を出力するためのツールキットである。本仕様書は、SRTrack Exporter、SRTrack Object、編集用 Preview モジュール、および GCMZDrops2 連携の SRTrack Importer を共通の目的に沿って整理する。

## コア・コンセプト

SRTrack は、**レンダリング済み動画を切り貼りして再編集しても、元の字幕情報を失わずに、編集後の動画に対応する SRT を再構成できるようにする**ためのツールキットである。

AviUtl2 のプロジェクト内にある字幕オブジェクトには、字幕本文と正確なタイミングが残っている。SRTrack Exporter はそれらを読み取り、YouTube などで使える SRT として出力する。

しかし、一度レンダリングした動画を別のプロジェクトで連結、切り抜き、分割、速度変更すると、動画ファイル単体には字幕の元データが残らない。音声認識で字幕を作り直す方法では、元の文字列やタイミングを十分に再現できない場合がある。

そこで SRTrack Importer は、GCMZDrops2 の公開ハンドラー API を使う動画配置の入口で、同じフォルダにある同名 SRT を検出した場合に、動画と対応する SRTrack Object を一組として生成・グループ化する。Importer は動画オブジェクトと同じフレーム境界の終端を Object の参照範囲終端と動画全長として初期化する。SRTrack Object は、ある動画と、その動画を出力した時点の SRT を対応づけ、動画オブジェクトの再生開始、終了位置、速度などの時間的な挙動に同期して SRT の参照範囲を表す。SRTrack Exporter はその結果を他の字幕ソースとともに出力する。

このため、SRTrack Object は字幕を動画へ描画するためのオブジェクトでも、単に手動で SRT の時刻を調整するだけのオブジェクトでもない。**動画オブジェクトの編集結果を字幕情報へ正確に引き継ぐ、対応する動画の字幕側の相方**である。編集画面だけの補助プレビューは、この主目的を変えない。

動画との対応づけ、再生開始・終了、速度、トリミング、分割への追従は、この概念から導かれる中核要件である。仕様上の選択がある場合は、レンダリング済み動画の再編集後にも元字幕をできる限り正確に再構成できるかを最優先の判断基準とする。

SRTrack では、動画ファイルと SRTrack Object を一組として作成・グループ化し、移動、分割、伸縮などの編集結果を両者で同期させることを目標とする。

## 現在の実装状況

| 要素 | 状態 |
| --- | --- |
| SRTrack Exporter | 実装済み。標準テキストからの字幕取得と SRT 出力は AviUtl2 2.1.13 で確認済み。 |
| 外部字幕準備オブジェクトの読取り | 実装済み。実機での互換性・設定値の保存形式は未検証。 |
| SRTrack Object | SRT の参照・再生設定と、編集用の非出力字幕プレビューを実装済み。簡易実機確認済み。 |
| SRTrack Object からの出力 | SRT 解析・固定正速度での時間変換を実装済み。簡易実機確認済み。 |
| 字幕プレビュー | SRTrack Object 単体の編集用プレビューと読込失敗表示を実装済み。Exporter 統合結果との一致は対象外。 |
| SRTrack Importer | 同名 SRT の検出、動画と Object の生成・グループ化、`P`・`E`・`D`・速度の初期化を実装済み。単体・複数ドロップを簡易確認済み。 |

上記の実機確認は開発者による概略確認であり、網羅的な受け入れ試験ではない。移動・分割・伸縮への自動追従とループは未実装である。

## 初期版の到達点

初期版は、UTF-8 SRT を参照する非出力の読み込みオブジェクトをタイムラインに置き、固定の正の速度・ループなしの範囲で、元 SRT の区間を編集後のシーン時刻に変換して出力できることを目標とする。標準テキスト、対応する外部字幕準備オブジェクト、SRT 由来の字幕を混在できることを目指す。
