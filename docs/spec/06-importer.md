# 6. Importer

## 6.1 最低限の役割

SRTrack Importer は、Windows 標準エクスプローラーおよび AviUtl2 内メディアエクスプローラーからの**動画ファイルのドロップ**を支援する機能である。

GCMZDrops2 の公開ハンドラースクリプト API を入口にし、L-SMASH Works と標準 AVI 読込を前提とする。SRTrack はこれらの外部プラグインを同梱・解析しない。

対象は `.avi` と、導入済み L-SMASH Works の読込対象として扱う次の拡張子である。

```text
mp4, m4v, m4a, mov, qt, 3gp, 3g2, f4v, ismv, isma,
mpg, mpeg, m1v, mts, m2t, m2ts, ts, vob, dv, flv,
mkv, webm, wmv, asf, lwi, avs, vpy
```

拡張子だけでは映像の有無を判定できないため、実際に取り込むのは GCMZDrops2 の公開メディア情報 API で動画トラックを得られるファイルだけとする。

## 6.2 動画と同名 SRT の取込

対象動画がドロップされたとき、Importer は同じフォルダで拡張子だけを `.srt` に置き換えたファイルを探索する。

```text
movie.mp4  →  movie.srt
```

同名 SRT と動画トラックの両方を確認できた場合、Importer は元動画を一時の複数 Object `.object` エイリアスに置き換える。このエイリアスには次の二つを含める。

1. 下側レイヤーの標準 `動画ファイル` Object
2. その直上レイヤーの `SRTrack Object`

二つには同じグループ値を設定する。これにより動画と字幕 Object を一組として移動・編集しやすくする。SRTrack Object の字幕参照条件はグループ ID ではなく直上動画である。

SRTrack Object には、検出した SRT パス、元動画の長さを表す `動画全長 D`、字幕プレビュー有効を設定する。動画と Object は同じ開始フレーム・同じ長さで配置する。

複数の対応動画を同時にドロップした場合は、ファイル名順に同じ二層へ時間方向に並べる。各動画と対応する SRTrack Object だけを同じグループにする。

`drag_enter` は拡張子だけを判定し、ファイルを開かない。同名 SRT の確認、動画トラックの取得、エイリアス生成は `drop` 内で行う。

## 6.3 今回の実装範囲外

次の項目は Importer の最低限の取込を安定させるまで努力目標とし、現在の完成条件に含めない。

- SRT ファイル単体のドロップ
- Importer 内部エラー時に GCMZDrops2 の他ハンドラーへ確実に委譲する高度なフォールバック
- SRTrack 全体設定、Importer のオン・オフ、単体 SRT ドロップの設定
- Object 表示名の SRT ファイル名への変更
- 同名 SRT がない場合の個別通知や追加処理

これらを実装しないことは、最低限の動画＋同名 SRT のグループ取込を妨げない。

## 6.4 完成条件

次を満たした時点で Importer の初期版完成とする。

1. Windows 標準エクスプローラーからの対象動画ドロップで、同名 SRT がある場合に動画と SRTrack Object が二層で配置され、グループ化される。
2. AviUtl2 内メディアエクスプローラーからも同じ結果になる。
3. 動画と SRTrack Object は同じ開始位置・長さとなり、動画全長 `D` が設定される。
4. 複数の対応動画を同時にドロップした場合、同じ二層へファイル名順で並び、異なる動画の組同士はグループ化されない。
