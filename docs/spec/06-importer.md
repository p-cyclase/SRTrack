# 6. Importer

## 6.1 役割

Importer は、動画ファイルをタイムラインへ配置する入口で、同じフォルダの同名 SRT を見つけた場合に `SRTrack Link Object` を初期配置する。GCMZDrops2 の公開ハンドラースクリプト API が受け取るファイルドロップを対象とする。GCMZDrops2 と L-SMASH Works は前提プラグインであり、SRTrack は同梱・解析しない。

Importer は字幕の時間変換、動画変更の監視、SRT パスの追従を行わない。同名 SRT の検出は初期値の利便性のためだけであり、以後の SRT ファイル指定は利用者が管理する。

## 6.2 取込時の処理

1. 動画トラックとして認識できるファイルがドロップされる。
2. 同じフォルダで拡張子だけを `.srt` に置き換えた同名 SRT を探す。
3. SRT がある場合、標準動画 Object と Link Object を含む一時の複数 Object エイリアスを生成する。
4. 動画を下側、Link Object をその直上へ、同じ開始・同じ長さで配置する。二段を置けない場合は、既存 Object を動かさず二段とも空く最初の後方時刻へ配置する。
5. 両者には同じグループ値を設定する。これは上下関係を保ちやすくする補助であり、Link Object の参照条件ではない。
6. Link Object の `SRT ファイル` に見つけたパス、`動画全長 D` に元動画の長さを設定する。`D` は以後の移動・分割・伸縮では変更しない。
7. Object 名は対応する SRT ファイル名へ設定する。

複数動画を同時にドロップする場合は、ファイル名順に同じ二層へ時間方向に並べ、各動画・Link Object の組だけを同じグループにする。同名 SRT がない場合はファイルリストを変更せず、動画だけを通常どおり配置し、通知を表示しない。

## 6.3 対応範囲と検証

エクスプローラーと AviUtl2 内メディアエクスプローラーからのドロップ、同名 SRT の検出、二層配置、ペアごとのグループ化、複数動画のファイル名順配置は現行実装で概略確認済みである。新しい Link Object の項目構成と `D` 初期化は次期実装・再検証の対象である。

固定の対応拡張子一覧は持たず、導入済みの L-SMASH Works または標準 AVI 読込が動画トラックとして認識できる形式を対象にする。外部製作物のリバースエンジニアリングは行わない。
