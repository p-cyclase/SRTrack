# 6. Importer

## 6.1 役割

Importer は、動画ファイルをタイムラインへ配置する入口で、同じフォルダの同名 SRT を見つけた場合に `SRTrack Object` を初期配置する。GCMZDrops2 の公開ハンドラースクリプト API が受け取るファイルドロップを対象とする。GCMZDrops2 と L-SMASH Works は前提プラグインであり、SRTrack は同梱・解析しない。

Importer は字幕の時間変換、動画変更の監視、SRT パスの追従を行わない。同名 SRT の検出は初期値の利便性のためだけであり、以後の SRT ファイル指定は利用者が管理する。

Importer が動画ドロップを扱うかどうかは、SRTrack 共通設定の `同名 SRT 自動取込` に従う。オフなら動画ドロップのファイル一覧を変更せず、通常の入力プラグインへ渡す。設定と即時反映の詳細は [08-settings.md](08-settings.md) を参照する。

## 6.2 取込時の処理

1. 動画トラックとして認識できるファイルがドロップされる。
2. 同じフォルダで拡張子だけを `.srt` に置き換えた同名 SRT を探す。
3. SRT がある場合、標準動画 Object と SRTrack Object を含む一時の複数 Object エイリアスを生成する。
4. 動画を下側、SRTrack Object をその直上へ、同じ開始・同じ長さで配置する。二段を置けない場合は、既存 Object を動かさず二段とも空く最初の後方時刻へ配置する。
5. 両者には同じグループ値を設定する。これは上下関係を保ちやすくする補助であり、SRTrack Object の参照条件ではない。
6. SRTrack Object の `SRT ファイル` に見つけたパス、`動画全長 D` に元動画の長さを設定する。長さを取得できない場合は `D=0` とする。`D` は以後の移動・分割・伸縮では変更しない。
7. Object 名は対応する SRT ファイル名へ設定する。

複数動画を同時にドロップする場合は、ファイル名順に同じ二層へ時間方向に並べ、各動画・SRTrack Object の組だけを同じグループにする。同名 SRT がない場合はファイルリストを変更せず、動画だけを通常どおり配置し、通知を表示しない。

## 6.3 SRT 単体のドロップ

`.srt` だけがドロップされた場合の扱いは、動画の同名 SRT 自動取込とは別に、SRTrack 共通設定の `SRT ファイル単体のドロップ` で選ぶ。

| 設定値 | 処理 |
| --- | --- |
| `SRTrack Object` | SRT パスを設定した SRTrack Object を単体で配置する。直上に動画がある区間だけが有効な字幕ソースとなる。 |
| `SRTrack Object (Standalone)` | SRT パスを設定した Standalone Object を単体で配置する。動画への参照はしない。 |
| `処理しない` | ファイル一覧を変更せず、他の入力プラグインへ渡す。 |

SRTrack が Object を配置する場合、SRT の有効な字幕区間の最大終了時刻を Object 長にする。不正な SRT または有効な字幕がない SRT は最小 1 フレームの長さにする。動画とのグループ化や `D` の初期設定は行わない。

## 6.4 失敗時の委譲

Importer は、一時エイリアスの生成を作業用のファイル一覧で完了させてから、成功時だけ AviUtl2 に渡す一覧を置換する。設定無効、対象外、SRT 不在、メディア情報取得失敗、一時ファイル作成・書込み失敗、Lua の例外では、元のファイル一覧を変更せず通常の入力プラグインへ渡す。

一時エイリアスを渡した後に AviUtl2 がエイリアスを読めない失敗は、GCMZDrops2 のハンドラーへ戻らない。そのため生成側で Object のエフェクト名と配布ファイル名の一致を保ち、問題を事前に防ぐ。利用者は共通設定から Importer 全体を無効化して通常読込へ戻せる。

## 6.5 対応範囲と検証

エクスプローラーと AviUtl2 内メディアエクスプローラーからのドロップ、同名 SRT の検出、二層配置、ペアごとのグループ化、複数動画のファイル名順配置は現行実装で概略確認済みである。新しい SRTrack Object の項目構成と `D` 初期化は次期実装・再検証の対象である。

固定の対応拡張子一覧は持たず、導入済みの L-SMASH Works または標準 AVI 読込が動画トラックとして認識できる形式を対象にする。外部製作物のリバースエンジニアリングは行わない。
