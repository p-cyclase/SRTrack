# 6. Importer

## 6.1 最低限の役割

SRTrack Importer は、Windows 標準エクスプローラーおよび AviUtl2 内メディアエクスプローラーからのファイルドロップを支援する機能である。

GCMZDrops2 の公開ハンドラースクリプト API を入口にし、L-SMASH Works と標準 AVI 読込を前提とする。SRTrack はこれらの外部プラグインを同梱・解析しない。

動画と同名 SRT の組取込は GCMZDrops2 の公開ハンドラースクリプト API を使用する。一方、SRT 単体は AviUtl2 公式 SDK の `.srt` 専用ファイルドロップ・ハンドラーで受け付ける。このハンドラーは動画拡張子を登録しないため、L-SMASH Works を含む既存の動画入力経路には介入しない。

対象は `.avi` と、導入済み L-SMASH Works の読込対象として扱う次の拡張子である。

```text
mp4, m4v, m4a, mov, qt, 3gp, 3g2, f4v, ismv, isma,
mpg, mpeg, m1v, mts, m2t, m2ts, ts, vob, dv, flv,
mkv, webm, wmv, asf, lwi, avs, vpy
```

拡張子だけでは映像の有無を判定できないため、実際に取り込むのは GCMZDrops2 の公開メディア情報 API で動画トラックを得られるファイルだけとする。

## 6.2 動画と同名 SRT の取込

対象動画がドロップされたとき、Importer は同じフォルダで拡張子だけを `.srt` に置き換えたファイルを探索する。

```text
movie.mp4  →  movie.srt
```

同名 SRT と動画トラックの両方を確認できた場合、Importer は元動画を一時の複数 Object `.object` エイリアスに置き換える。このエイリアスには次の二つを含める。

1. 下側レイヤーの標準 `動画ファイル` Object
2. その直上レイヤーの `SRTrack Object`

二つには同じグループ値を設定する。これにより動画と字幕 Object を一組として移動・編集しやすくする。SRTrack Object の字幕参照条件はグループ ID ではなく直上動画である。

SRTrack Object には、検出した SRT パス、元動画の長さを表す `動画全長 D`、字幕プレビュー有効を設定する。動画と Object は同じ開始フレーム・同じ長さで配置する。

複数の対応動画を同時にドロップした場合は、ファイル名順に同じ二層へ時間方向に並べる。各動画と対応する SRTrack Object だけを同じグループにする。

`drag_enter` は拡張子だけを判定し、ファイルを開かない。同名 SRT の確認、動画トラックの取得、エイリアス生成は `drop` 内で行う。

動画ペア化に必要な処理は、元の `files` 一覧を変更する前にすべて完了させる。プロジェクト情報・メディア情報・SRT の確認・一時エイリアス生成のいずれかに失敗した場合、Importer は一覧を変更せず終了する。GCMZDrops2 は変更後の一覧を AviUtl2 へ渡すため、この場合は元動画が通常の入力プラグイン経路で処理される。

## 6.3 SRT 単体のドロップ

`.srt` 単体をドロップした場合、Importer は AviUtl2 SDK の Object 作成 API で `SRTrackObject` を直接一つ配置する。動画との組、グループ、複数 Object エイリアスを必要としないため、この経路で一時 `.object` エイリアスは生成しない。SRT の最大終了時刻を Object 長とし、有効な時刻を得られない場合は最小 1 フレームとする。

この初期実装は、動画とグループ化せず、`動画全長 D` を `0` に設定する。SRT 単体取込では `SRTrackObject(Standalone)` も選べるが、既定は直上動画が必要な `SRTrackObject` とする。選択値は Importer 設定で保存し、AviUtl2 の次回起動時から適用する。

## 6.4 今後の改善候補

次の項目は Importer 初期版の完成条件に含めない。

- Object 表示名の SRT ファイル名への変更
- 同名 SRT がない場合の個別通知や追加処理

これらを実装しないことは、動画＋同名 SRT のグループ取込および SRT 単体取込を妨げない。

## 6.5 完成条件

次を満たしたため、Importer は初期版完成とする。AviUtl2 2.1.13 と開発環境での確認は概略的なものであり、他プラグインとの網羅的な組合せ試験は今後の互換性確認として扱う。

1. Windows 標準エクスプローラーからの対象動画ドロップで、同名 SRT がある場合に動画と SRTrack Object が二層で配置され、グループ化される。
2. AviUtl2 内メディアエクスプローラーからも同じ結果になる。
3. 動画と SRTrack Object は同じ開始位置・長さとなり、動画全長 `D` が設定される。
4. 複数の対応動画を同時にドロップした場合、同じ二層へファイル名順で並び、異なる動画の組同士はグループ化されない。
5. `.srt` 単体をドロップした場合、SRT パスを持つ `SRTrackObject` が一つ配置される。
6. Importer 設定の保存後に AviUtl2 を再起動すると、動画ペア取込、SRT 単体取込、SRT 単体の Object 種別の選択が反映される。
