# 5. エラー、互換性、検証

## 5.1 エラー時の原則

- プロジェクト・シーン情報、対象オブジェクト、設定値、SRT ファイル、保存先の取得に失敗した理由を表示する。
- 対象字幕が 0 件なら空の SRT は作成しない。
- 読み取れない入力を黙って欠落させない。部分出力を許す場合も、対象と理由を警告する。
- 出力成功時は、保存先、取得件数、出力件数、除外件数、警告件数を表示する。
- SRTrack Object の編集用プレビューで SRT を読めない場合は、空表示にせず、編集画面に読込失敗を明示する。ファイル出力中はこの診断表示も描画しない。
- エラー、警告、保存のキャンセルで、元のプロジェクトやオブジェクトを変更しない。

## 5.2 互換性と依存関係

- 当面の対象は AviUtl ExEdit2 2.1.13。
- SRTrack Exporter は AviUtl2 Plugin SDK の同梱ヘッダーを使用する。SDK の日付だけで互換性を判断しない。
- SRTrack Importer は GCMZDrops2 と L-SMASH Works を前提プラグインとする。いずれも同梱せず、GCMZDrops2 は公開ハンドラースクリプト API のみを利用する。固定の対応拡張子一覧は持たず、導入済みの L-SMASH Works または標準 AVI 読込が動画トラックとして認識できる形式を対象にし、複数オブジェクト・エイリアス内の標準動画オブジェクトへファイル参照を設定する。
- SRTrack Object の設定取得、SRT 出力、`SRTrack.mod2` に相当する Preview モジュールによる日本語パス読込とループ、GCMZDrops2 経由の同名 SRT 検出・二層配置・ペアごとのグループ化・複数動画のファイル名順配置は AviUtl2 2.1.13 で概略確認済み。厳密な網羅試験は未実施である。

### 外部製作物の扱い

SRTrack は、公開されている AviUtl2 の公式ドキュメントと Plugin SDK に基づく独立した実装とする。AviUtl2 標準オブジェクト以外の外部ファイルおよび外部製作物について、リバースエンジニアリングを行わない。

## 5.3 検証項目

### SRT 解析

1. UTF-8 BOM の有無、CRLF／LF、末尾空行、複数行本文。
2. 不正 UTF-8、不正時刻、番号欠落・重複、逆転区間、時刻順でない区間、重複区間、空白区間。
3. ファイル変更・移動・欠落・アクセス拒否。

### 時間変換

1. 等速、倍速、半速、再生開始位置、オブジェクト範囲からはみ出す字幕、境界一致。
2. 30 fps と分数フレームレート、長時間、端数時刻、再出力時の丸め誤差。
3. オブジェクト全体の移動の結果を標準動画と比較する。端変更・分割・伸縮は、Monitor がグループ内の標準動画の更新結果を Object へ継続反映できるようになるまで保留とする。
4. GCMZDrops2 経由の動画ドロップ時に同名 SRT を参照する SRTrack Object が生成され、動画とグループ化されることを確認する。
5. 動画と SRTrack Object を組にして、移動、再生開始位置、速度変更の結果が同期することを確認する。分割・伸縮の同期試験は、Monitor を実装してから追加する。
6. SRTrack Importer が GCMZDrops2 経由で動画を受け取った場合、同じフォルダの同名 SRT を検出し、動画と Object を標準の複数オブジェクト・エイリアスから生成・グループ化して、動画オブジェクトと同じフレーム境界終端で `E` と `D` を初期化できることを確認する。動画と Object の二段分を置ける最初の後方時刻への配置と既存オブジェクトが移動しないことも確認する。
7. Importer が動画全長 `D` を保存し、移動・分割・伸縮の前後で `D` が変化しないことを確認する。ループ再生時は `D` を周期として利用し、プレビューと Exporter が同じ字幕反復結果になることを検証する。
8. `P`、`E`、再生速度、`D` を手動変更した場合に、動画との対応が崩れる可能性を Object の UI または利用案内で確認できることを確認する。変更そのものは拒否・自動差し戻ししない。
9. Importer がエクスプローラーおよび AviUtl2 内メディアエクスプローラーからのファイルドロップで同じ結果を作ることを確認する。その他の追加経路は対象外とする。
10. 同名 SRT がない動画をドロップした場合、動画だけが通常どおり配置され、通知が表示されないことを確認する。
11. Monitor を実装する場合、動画側の `P`・`E`・再生速度の更新結果が Object に反映されること、`D` が不変であること、手動値の扱いが仕様どおりであることを確認する。
12. Object の `再生位置` と `再生範囲終端` が秒単位で確認・編集でき、再生速度が標準動画と同じ百分率表示となることを確認する。現行 UI は標準動画の開始・終端を一つにまとめた二値 UI と同一の外観ではない。

### 編集用字幕プレビュー

1. `字幕プレビュー` のオン・オフで、編集画面の SRT 字幕表示だけが切り替わることを確認する。
2. 再生開始位置と正の固定速度を変更し、`P + v × obj.time` に対応する SRT 字幕が表示されることを確認する。
3. ファイル出力時にプレビュー文字が動画へ描画されないことを確認する。
4. 外部で SRT を更新後、「キャッシュを破棄」で表示も更新されることを確認する。
5. Lua 側で SRT を読めない場合、編集画面には読込失敗が表示され、ファイル出力には診断文字を含めないことを確認する。
6. SRT 本文と読込失敗表示の両方について、標準の描画設定・オブジェクト順序にかかわらず編集画面で描画されることを確認する。
7. 日本語を含むフォルダ名・ファイル名の UTF-8 SRT を指定し、完成時の `SRTrack.mod2` 経由で字幕を表示できることを確認する。

### 出力統合

1. SRT、標準テキスト、対応する外部字幕準備オブジェクトを単独・混在で出力する。
2. レイヤー選択、同時刻、重複、空白、結合、オフセット、0 秒以下の区間を確認する。
3. 既存の SRTrack Exporter の出力結果と設定が損なわれないことを確認する。
4. SRT 字幕を標準テキストまたはセリフ準備が中断した場合、中断された同じ SRT 字幕が再開せず、次の SRT 字幕だけが本来の開始時刻に開始することを確認する。
5. 中断による短い字幕が結合閾値に従って結合されることを確認する。

## 5.4 現在の検証状態

標準テキストからの字幕取得と SRT 出力、SRTrack Object の配置・SRT 出力・編集用プレビュー・日本語パス読込・再生位置と正の固定再生速度への追従は AviUtl2 2.1.13 で開発者が概略確認済みである。`D` 周期の字幕プレビューも確認済みである。厳密な網羅試験ではない。ループ時の Exporter 出力、外部字幕準備オブジェクト、レイヤー指定、オフセット、設定保存、SRT と他字幕の統合規則、ファイル出力へプレビュー文字が混入しないこと、YouTube Studio への取り込みは未検証または未実装である。
