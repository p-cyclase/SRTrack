# 9. Preview／Exporter 手動回帰テスト

## 9.1 目的と範囲

Git 管理するテスト用 AviUtl2 プロジェクトを用意し、SRTrack の Preview と Exporter に対する代表的な手動回帰確認を、同じ素材・同じ配置で繰り返せるようにする。

このプロジェクトは Importer のテストを目的としない。Importer は空シーンへ動画または SRT をドロップする操作自体が確認対象であるため、別の手動チェックとして扱う。

PSDToolKit のセリフ準備は外部プラグインに依存する。基本プロジェクトの必須条件には含めず、導入環境で実施する任意確認とする。

## 9.2 配置と管理方針

管理位置は次のとおりとする。

```text
tests/
  manual/
    SRTrack-Regression.aup2
    README.md
    checklist.md
    fixtures/
      regression-video.mp4
      regression-video.srt
      standalone.srt
```

- 素材は短い自作動画と、権利関係が明確なテスト字幕だけを使う。基準動画にはSRTの各区間と対応する表示を含め、Previewを目視比較できるようにする。
- AviUtl2 が保存する `.aup2` の参照先は現時点では絶対パスである。配布・別環境で開く場合は、`fixtures/` 内の同名ファイルを指定し直す手順を `README.md` に案内する。
- 実動画や個人制作物、外部プラグインの配布物は同梱しない。
- テストプロジェクトは、初期設定を変更しない状態で開く。確認ごとの設定変更は `checklist.md` に明記する。

## 9.3 基準設定

Exporter の基準は初期設定とする。

| 項目 | 基準値 |
| --- | --- |
| 最小表示時間 | `1.000` 秒 |
| 出力対象時間範囲 | シーン全体 |
| 対象レイヤー | すべてのレイヤー |
| 対象 Object | テキスト、SRTrack Object（Standalone を含む） |
| ルビ・絵文字のカッコ書き | オン |
| 待機・クリアを反映 | オン |
| 同時開始時の並び順 | 上のレイヤーから（Layer 1 側） |

短い字幕や `<c0.5>` の確認も、基準設定では1秒未満の候補が結合・延長されることを期待結果とする。字幕境界そのものを確認する限定ケースだけ、最小表示時間を `0.500` 秒へ変更する。その変更は確認後に基準値へ戻す。

## 9.4 プロジェクト内の必須ケース

### Preview

1. SRTrack Object を動画の1つ下のレイヤーへ置き、読み込んだ SRT の字幕が編集画面に表示される。
2. 動画と Object のタイムライン開始位置をずらして置き、動画の対応位置の字幕が表示される。
3. 動画の再生開始位置と再生速度を変更し、Preview が追従する。
4. Object の範囲中で1つ上のレイヤーに動画がない区間では、Preview が専用診断を表示する。
5. Standalone Object は、自身の再生位置・速度に従って字幕を表示する。
6. `字幕プレビュー` のオン・オフが編集画面だけに反映され、動画出力には描画されない。

### Exporter

1. 標準テキスト、SRTrack Object、Standalone Object を同一プロジェクトから出力する。
2. 各字幕候補は、別候補の開始・Object 終端・SRTrack Object の参照動画不在で終了する。
3. 同時開始の複数テキストを置き、上のレイヤーからの本文順と、短い字幕の結合を確認する。
4. `<r>`、`<w>`、`<c>`、倍率付き待機・クリア、ルビ、絵文字、コメント、Lua スクリプトを含むテキストを出力する。
5. 基準設定の最小表示時間 `1.000` 秒で、短い候補が想定どおり結合・延長されることを確認する。
6. 限定ケースとして最小表示時間を `0.500` 秒へ変更し、`<r10>AB<c0.5>CD` などのクリア境界がSRT候補として出力されることを確認する。
7. フレーム範囲選択出力で、範囲端をまたぐ字幕の切り出しと、選択開始を `00:00:00,000` とする再基準化を確認する。
8. `上のレイヤーから` と `下のレイヤーから` を切り替え、同時開始字幕の本文順だけが変わることを確認する。

## 9.5 記録方法

`checklist.md` では各ケースについて、操作、期待する Preview または SRT の結果、確認日、AviUtl2・SRTrack の版、結果を記録する。確認済みは「概略確認」であり、全フレーム・全環境を網羅した保証とは扱わない。
