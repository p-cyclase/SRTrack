# 9. Preview／Exporter 手動回帰テスト

## 9.1 目的と範囲

Git 管理するテスト用 AviUtl2 プロジェクトを用意し、SRTrack の Preview と Exporter に対する代表的な手動回帰確認を、同じ素材・同じ配置で繰り返せるようにする。

このプロジェクトは Importer のテストを目的としない。Importer は空シーンへ動画または SRT をドロップする操作自体が確認対象であるため、別の手動チェックとして扱う。

PSDToolKit のセリフ準備は外部プラグインに依存する。基本プロジェクトの必須条件には含めず、導入環境で実施する任意確認とする。

## 9.2 配置と管理方針

管理位置は次のとおりとする。

```text
tests/
  manual/
    SRTrack-Regression.aup2
    README.md
    checklist.md
    fixtures/
      regression-video.mp4
      regression-video.srt
      standalone.srt
```

- 素材は短い自作動画と、権利関係が明確なテスト字幕だけを使う。基準動画にはSRTの各区間と対応する表示を含め、Previewを目視比較できるようにする。
- AviUtl2 が保存する `.aup2` の参照先は現時点では絶対パスである。配布・別環境で開く場合は、`fixtures/` 内の同名ファイルを指定し直す手順を `README.md` に案内する。
- 実動画や個人制作物、外部プラグインの配布物は同梱しない。
- テストプロジェクトは、初期設定を変更しない状態で開く。確認ごとの設定変更は `checklist.md` に明記する。

## 9.3 基準設定

Exporter の基準は初期設定とする。

| 項目 | 基準値 |
| --- | --- |
| 最小表示時間 | `1.000` 秒 |
| 出力対象時間範囲 | シーン全体 |
| 対象レイヤー | すべてのレイヤー |
| 対象 Object | テキスト、SRTrack Object（Standalone を含む） |
| ルビ・絵文字のカッコ書き | オン |
| 待機・クリアを反映 | オン |
| 同時開始時の並び順 | 上のレイヤーから（Layer 1 側） |

短い字幕や `<c0.5>` の確認も、基準設定では1秒未満の候補が結合・延長されることを期待結果とする。字幕境界そのものを確認する限定ケースだけ、最小表示時間を `0.500` 秒へ変更する。その変更は確認後に基準値へ戻す。

## 9.4 プロジェクト内の必須ケース

### Preview

1. SRTrack Object を動画の1つ下のレイヤーへ置き、読み込んだ SRT の字幕が編集画面に表示される。
2. 動画と Object のタイムライン開始位置をずらして置き、動画の対応位置の字幕が表示される。
3. 動画の再生開始位置と再生速度を変更し、Preview が追従する。
4. Object の範囲中で1つ上のレイヤーに動画がない区間では、Preview が専用診断を表示する。
5. Standalone Object は、自身の再生位置・速度に従って字幕を表示する。
6. `字幕プレビュー` のオン・オフが編集画面だけに反映され、動画出力には描画されない。

### Exporter

1. 標準テキスト、SRTrack Object、Standalone Object を同一プロジェクトから出力する。
2. 各字幕候補は、別候補の開始・Object 終端・SRTrack Object の参照動画不在で終了する。
3. 同時開始の複数テキストを置き、上のレイヤーからの本文順と、短い字幕の結合を確認する。
4. `<r>`、`<w>`、`<c>`、倍率付き待機・クリア、ルビ、絵文字、コメント、Lua スクリプトを含むテキストを出力する。
5. 基準設定の最小表示時間 `1.000` 秒で、短い候補が想定どおり結合・延長されることを確認する。
6. 限定ケースとして最小表示時間を `0.500` 秒へ変更し、`<r10>AB<c0.5>CD` などのクリア境界がSRT候補として出力されることを確認する。
7. フレーム範囲選択出力で、範囲端をまたぐ字幕の切り出しと、選択開始を `00:00:00,000` とする再基準化を確認する。
8. `上のレイヤーから` と `下のレイヤーから` を切り替え、同時開始字幕の本文順だけが変わることを確認する。

## 9.5 記録方法

`checklist.md` では各ケースについて、操作、期待する Preview または SRT の結果、確認日、AviUtl2・SRTrack の版、結果を記録する。確認済みは「概略確認」であり、全フレーム・全環境を網羅した保証とは扱わない。

固定の正解 SRT は管理しない。SRTrack は開発中であり、実装・仕様を変更するたびに固定期待値を更新すると、期待値自身の誤りや古い仕様への追従を見落とすためである。出力された SRT とテストマップを照合し、各ケースで何が起きたかを観察・検討する。

## 9.6 拡張版プロジェクトの具体設計

現在の30秒プロジェクトは、素材読込の確認を済ませるための初期試作とする。以下の構成へ拡張して置き換え、SRTrack を更新するたびに「プロジェクトを開く → 標準設定で Exporter を実行 → 出力 SRT を確認する」だけで基礎挙動を一巡できる実験場にする。

### 素材の再利用

`fixtures/regression-video.mp4`（30秒・30fps）と `fixtures/regression-video.srt` は作り直さない。同じ動画ファイルを複数の動画 Object から参照し、再生開始位置・再生速度・タイムライン位置だけを変える。動画に含まれる3秒ごとの基準表示と、同名 SRT の `映像基準 A`〜`J` は、各動画追従ケースの目視確認にも使う。

`standalone.srt` は Standalone 専用の識別本文を持つ小さな fixture とする。動画素材を追加する必要はない。

### タイムライン配置

拡張版の全長はおよそ150秒とする。表中の「動画」は SRTrack Object の1つ上のレイヤーへ置き、同じ行の Object はその直下に置く。

| 区間 | 動画／Object の設定 | 配置する本文 | 主な観察点 |
| --- | --- | --- | --- |
| 0〜30秒 | 動画 `P=0`、速度100%、動画追従Object | `映像基準 A`〜`J` | 基本 Preview、基本 SRT読込、通常速度 |
| 30〜45秒 | 同じ動画 `P=0`、速度200%、動画追従Object | 圧縮された `映像基準 A`〜`J` | 動画速度と字幕時刻の追従 |
| 45〜60秒 | 同じ動画 `P=10`、速度100%、動画追従Object | `映像基準 D`以降 | 動画の再生開始位置 |
| 60〜75秒 | 動画 `P=0`、速度100%、Objectは63秒から開始 | `映像基準 B`以降 | 動画とObjectのタイムライン開始位置差 |
| 75〜90秒 | 動画を置かず、動画追従Objectだけを置く | SRTは指定したまま | Previewの専用診断、Exporterでは該当区間を字幕なしとして継続 |
| 90〜105秒 | Standalone Object、`P=0`、速度100% | `STANDALONE-A`等 | Standaloneの基本出力・Preview |
| 105〜110秒 | 標準テキストを4レイヤー同時開始 | `SIM-A`〜`SIM-D` | 同時開始、上／下レイヤー順、短い字幕の結合 |
| 110〜116秒 | 標準テキスト | `<r10>AB<c0.5>CD` | `<r>`、`<c>`、初期値1秒での結合。必要時は最小表示時間0.500秒で境界を観察 |
| 116〜122秒 | 標準テキスト | `<r10>A<w1>B<w*0.2>CD` | `<r>`、`<w>`、`<w*>`、文字送りを個別SRTにしない処理 |
| 122〜128秒 | 標準テキスト | `<r10>AB<c*0.2>\nCD` | `<c*>`、`<c>`直後の改行無視、クリア後の次字幕 |
| 128〜134秒 | 標準テキスト | ルビ、絵文字、装飾、コメント、Lua | 各変換チェック、常時削除する構文 |
| 134〜140秒 | 動画追従Objectの範囲へ標準テキストを重ねる | `INTERRUPT` | 他字幕開始によるSRT候補の中断と、次の元SRT字幕の開始 |
| 140〜150秒 | Object終端を動画より早くする | `映像基準` の途中でObject終了 | Object終端による字幕終了 |

### 出力と観察の方法

初回は Exporter の基準設定（最小表示時間1.000秒、全レイヤー、全時間範囲、上のレイヤーから）でシーン全体を出力する。出力 SRT の本文にある `映像基準`、`STANDALONE`、`SIM`、`AB`／`CD`、`INTERRUPT` などを手掛かりに、対応する区間をテストマップから確認する。

必要な場合だけ、次の焦点化した追加出力を行う。

- 最小表示時間を `0.500` 秒へ変更し、110〜128秒の時間制御境界を観察する。
- 同時開始時の並び順を「下のレイヤーから」へ変更し、105〜110秒の本文順だけが反転するかを見る。
- フレーム範囲選択を設定して、SRT候補の範囲端での切出しと時刻のゼロ基準化を確認する。

これらの設定変更は恒久設定として残さず、確認後に基準値へ戻す。
