# 7. Monitor の初期実装方針

## 7.1 目的と責務

Monitor は `SRTrack.aux2` に収録する常駐コンポーネントである。Importer が作成した動画 Object と SRTrack Object の組について、標準動画 Object の編集結果を SRTrack Object へ反映する。

Monitor は標準動画の移動、分割、伸縮、再生範囲の更新規則を独自に再実装しない。AviUtl2 本体が標準動画へ反映した最終状態を読み取り、その結果を字幕側へコピーする。**動画 Object を正とし、SRTrack Object は従う。**

## 7.2 管理対象と組の判定

Monitor の管理対象は Importer が生成した SRTrack Object に限る。Importer は生成時に、その Object が動画同期の管理対象であることを永続的に記録する。手動配置した SRTrack Object は、明示的に管理対象化する仕組みを追加するまで Monitor は変更しない。

各管理対象 Object について、直下レイヤーにある標準の `動画ファイル` Object を候補にする。動画と Object の開始・終了フレームが一致していることは通常状態の結果であり、組を見つける前提条件にはしない。長さがずれている場合にも動画側へそろえる必要があるためである。

候補を一意に決められない場合、Monitor は同期しない。例えば、複数候補が同じ範囲に重なる、対応動画がない、動画と Object の位置関係が破損している場合が該当する。この場合は例外で停止したり、モーダルな警告を繰り返したりせず、診断情報だけを残す。

複数の動画 Object と SRTrack Object が利用者の操作で一つのグループにまとめられていても、各管理対象が一意に動画候補を持つ限りは、組ごとに個別同期する。一意性が失われた組だけを安全側でスキップし、他の組は処理する。

## 7.3 同期対象

Monitor は、対応動画 Object から次の値を SRTrack Object へ反映する。

| 対象 | 動画 Object を正とする処理 |
| --- | --- |
| タイムライン位置・開始フレーム | Object を動画の直上レイヤー・同じ開始フレームへ戻す |
| 終了フレーム・アイテム長 | Object の最終終了点を動画 Object と同じフレームへ移動する |
| 再生位置 `P` | 動画の再生位置を Object の `再生位置` へコピーする |
| 再生範囲終端 `E` | 動画の再生範囲終端を Object の `再生範囲終端` へコピーする |
| 再生速度 | 動画の再生速度を Object の `再生速度` へコピーする |
| ループ再生 | 動画の `ループ再生` を Object の `ループ再生` へコピーする |
| 動画全長 `D` | コピーしない。Importer が記録した元動画の全長を維持する |

利用者が SRTrack Object 側の `P`、`E`、再生速度、ループ再生、タイムライン位置、長さを手動変更しても、対応動画が一意に見つかる場合は次回同期時に動画側の値へ差し戻す。動画 Object 側の値を Object の変更から逆方向に更新することはない。

## 7.4 ファイル同期と Object 名

動画 Object の `ファイル` が変更された場合、Monitor は新しい動画ファイルと同じフォルダで、拡張子だけを `.srt` に置き換えたファイルを探す。

- 同名 SRT が存在する場合、Object の `SRT ファイル` をその絶対パスへ更新し、Object 名をその `.srt` のファイル名へ設定する。
- 同名 SRT が存在しない場合、Object の `SRT ファイル` を空文字へ更新し、Object 名を標準名 `SRTrack` に戻す。

後者では、編集用プレビューは SRT 未指定の診断を表示する。Monitor 自身はエラー表示を出さない。

利用者が SRTrack Object 側の `SRT ファイル` を変更した場合、対応動画が一意に見つかるなら、動画側の現在のファイルから上記と同じ規則を適用して差し戻す。動画 Object のファイルを SRT Object 側から変更することはない。

## 7.5 実行方式と非干渉性

Monitor は SDK の `UPDATE_OBJECT` 通知を使う。この通知はオブジェクト更新ごとに届くが、通知スレッドからプロジェクトを編集してはならない。

通知を受けた Monitor はメインスレッドへ同期処理を予約する。短時間に続く通知は一回にまとめ、編集操作が落ち着いた後だけ同期する。同期時は、実際に差がある値だけを書き換える。Monitor 自身の書き換えで発生する通知は、同値比較と予約の集約により繰り返し処理しない。

SRTrack Object が存在しない動画、管理対象でない SRTrack Object、または候補を一意に決められない組は変更しない。利用者が SRT と無関係な動画を編集する場合、Monitor は通知を受けても対象を作成・変更・通知しない。

## 7.6 初期実装の対象外

- 管理対象でない手動配置 Object の自動同期
- 一意でない組を利用者操作なしに推測・自動修復すること
- 速度 0、逆再生、可変速度、中間点、時間制御、シーンをまたぐ利用
- Monitor が同期できなかった理由をモーダルダイアログで都度通知すること

診断情報の閲覧方法と、手動配置 Object を管理対象へ昇格する UI は初期実装後に検討する。
