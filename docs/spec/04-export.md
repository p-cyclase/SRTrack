# 4. 字幕ソースの統合と SRT 出力

## 4.1 字幕ソース

SRTrack Exporter は次の情報を共通形式へ正規化して後段へ渡す。

| 項目 | 内容 |
| --- | --- |
| 開始・終了 | シーン時刻上の字幕区間 |
| 本文 | 改行を保持した字幕文字列 |
| 出所 | 標準テキスト、PSDToolKit セリフ準備、SRTrack Object |
| レイヤー | 安定した並び順と利用者による選択に使用 |
| 元順序 | 同時刻・同一ソース時の安定した順序に使用 |

実装済みの対象は標準テキストと PSDToolKit のセリフ準備である。SRTrack Object は、オブジェクト識別・設定取得・SRT 解析・時間変換を追加してから対象に含める。

## 4.2 現行エクスポーターの挙動

現行版では、対象レイヤーをシーン全体または番号・名前で選択し、標準テキストとセリフ準備を個別に選択できる。字幕を開始時刻順に並べ、最後以外の字幕の終了を次の字幕の開始に合わせる。短い字幕の結合、末尾の最小表示時間、全体オフセットを適用して SRT を出力する。

この規則は、元 SRT に含まれる意図的な空白区間・重複区間を変更する可能性がある。

## 4.3 SRT 由来の字幕の扱い（未決定）

次を決めずに、SRTrack Object の出力実装へ進まない。

- SRT の元区間・無字幕区間・重複をそのまま保持するか、現行の切替規則に統一するか。
- 他の字幕ソースと混在した場合、全ソースに同じ結合・オフセット規則を適用するか、出所ごとに扱いを分けるか。
- 複数 SRT と同時刻字幕の並び順・重複を保持、結合、選択のどれにするか。
- 空本文、書式、制御文字をどう扱うか。

出力ファイルの番号は、最終的な出力順に 1 から付け直す案とする。0 秒以下の区間は出力しない。

## 4.4 出力ファイル

- 形式：SubRip（`.srt`）
- 文字コード：UTF-8
- 時刻表記：`HH:MM:SS,mmm`
- 見た目：フォント、色、座標、縁取りは出力しない

字幕の制御文字、ルビ、絵文字、スクリプト文字列の変換は未実装である。元の文章を黙って校正・翻訳しない。
