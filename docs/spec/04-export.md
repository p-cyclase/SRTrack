# 4. 字幕ソースの統合と SRT 出力

> **実装状態**：Exporter は、二種類の SRTrack Object を含む字幕候補の統合、短字幕結合、フレーム範囲選択出力までの最小実装を完了している。現在は実機での検証とブラッシュアップ段階であり、初期版完成の判断は [全体仕様書](README.md) に記す未検証項目を確認した後に行う。

## 4.1 字幕ソース

SRTrack Exporter は次の情報を共通形式へ正規化して後段へ渡す。

| 項目 | 内容 |
| --- | --- |
| 開始・終了 | シーン時刻上の字幕区間 |
| 本文 | 改行を保持した字幕文字列 |
| 出所 | 標準テキスト、対応する外部字幕準備オブジェクト、SRTrack Object、SRTrack Object (Standalone) |
| レイヤー | 安定した並び順と利用者による選択に使用 |
| 元順序 | 同時刻・同一ソース時の安定した順序に使用 |

標準テキスト、対応する外部字幕準備 Object、`SRTrack Object`、`SRTrack Object (Standalone)` は、いずれも並列の字幕ソースである。一方を他方より本質的に優先するカテゴリにはしない。`SRTrack Object` は Object 範囲内で自身の1つ上のレイヤーにある動画ごとの有効区間を読み、開始位置差を含む時間変換を行う。`SRTrack Object (Standalone)` も `SRTrack Object` と同じ対象設定で字幕ソースに含める。

各 Object 単独の SRT 時刻は Preview と Exporter で一致させる。テキスト等との統合・結合・オフセット後の最終 SRT は Preview の対象外である。

## 4.2 字幕候補の統合

### 4.2.1 候補の生成

Exporter は、選択された各字幕ソースから字幕候補を生成する。

- 標準テキストと外部字幕準備 Object は、Object の開始を候補の開始、Object の終了を候補の終了とする。
- `SRTrack Object` と `SRTrack Object (Standalone)` は、SRT の各字幕をそれぞれ独立した候補とする。時間変換、有効区間、1つ上のレイヤーの動画がない区間は [時間変換と動画参照](03-timing.md) に従う。
- `SRTrack Object` では、1つ上のレイヤーに動画がない区間を候補に含めない。動画がなくなった時点で候補は終了し、後に再出現した場合は別の候補として開始する。

この段階で、候補の本文、開始・終了、レイヤー番号、同じレイヤー内での安定した元順序を保持する。SRT、テキスト、外部字幕準備を別々の優先カテゴリとしては扱わない。

### 4.2.2 開始・終了イベント

すべての候補を開始時刻順に処理する。候補が開始すると、直前に表示中の候補はその開始時刻で終了する。候補自身の終了時刻、Object の終了、または `SRTrack Object` における1つ上のレイヤーの動画の消失も、表示中の候補を終了する境界である。

中断された候補は再開しない。同じ SRT 内の後続字幕を含む別の候補は、本来の開始時刻で新たに開始する。

同一フレームに複数の候補が開始する場合は、Layer 1 側（レイヤー番号が小さい側）から順に開始イベントを処理する。同時開始順は**勝者を選ぶ優先順位ではない**。先に開始した候補が同時刻に終了することを許容し、すべての候補を内部結果に残す。同じレイヤー内では元順序で安定的に処理する。

たとえば同じフレームに Layer 1 から順に `a`、`b`、`c`、`d` が開始し、`d` が 1 秒間表示される場合、内部結果は順に 0 秒の `a`、0 秒の `b`、0 秒の `c`、1 秒の `d` となる。これらは後段の短字幕処理で 1 秒の `abcd` になる。

SRT 内で字幕時刻が重複することは正常入力として想定しない。検出した場合も同じ開始・終了規則を適用し、後から開始する候補が表示中の候補を終了する。

### 4.2.3 短い字幕の結合と延長

開始・終了イベントを処理した直後は、表示時間が 0 秒の候補も削除しない。「最小表示時間」は 0.500 秒以上で指定し、初期値は 1.000 秒とする。表示時間がこの値未満の候補は通常の短い字幕として時系列で直後の候補へ結合する。ゼロ秒字幕専用の例外処理は設けない。結合後の本文は先行候補の本文を後続候補の本文の前へ、初期実装では区切り文字を追加せずに連結する。各候補内に元からある改行は保持する。

結合先がない末尾候補は、同じ「最小表示時間」に達するまで終了時刻を延長する。延長後の字幕は、動画、シーン、選択範囲の終端を超えていても切り詰めず、そのまま SRT に出力する。動画時間を超える SRT を外部サービスがどう扱うかは実機観察後に別途判断する。結合と延長を終えた後も正の表示時間を得られない候補だけを出力から除外する。

本文の結合区切りを選べる設定は将来の改善項目とする。

### 4.2.4 出力時刻範囲と最終化

出力範囲はシーン全体または AviUtl2 のフレーム範囲選択とする。フレーム範囲選択では、範囲外の候補を除外し、範囲端をまたぐ候補は範囲内へ切り詰める。範囲開始時刻を `00:00:00,000` として全候補を再基準化する。

候補の統合、範囲による切り詰め、短い字幕の結合・延長、全体オフセットを順に適用して SRT を作る。番号は最終的な出力順に 1 から振り直す。

## 4.4 出力ファイル

- 形式：SubRip（`.srt`）
- 文字コード：UTF-8
- 時刻表記：`HH:MM:SS,mmm`
- 見た目：フォント、色、座標、縁取りは出力しない

字幕の制御文字、ルビ、絵文字、スクリプト文字列の変換は未実装である。元の文章を黙って校正・翻訳しない。実装時の変換規則は [4.7 テキスト制御文字](#47-テキスト制御文字) に従う。

## 4.5 保存先と動画書き出し範囲への配慮

SRTrack Exporter は、あくまで SRT を保存する通常のエクスポーターである。動画ファイルの書き出し、動画出力プラグインの操作、動画出力の成功・失敗・キャンセルとの連動は行わない。

SRT の保存時は通常の保存ダイアログを表示する。同名保存を強制せず、既存ファイルの上書き確認も OS の保存ダイアログに委ねる。

現行の Plugin SDK には、動画の書き出し先を直接取得する API はない。一方、保存済みの AviUtl2 プロジェクト（`.aup2`）はシーンごとに標準の `output.file` を記録する。Exporter は、SDK で取得した保存済みプロジェクトのパスを**読み取り専用**で開き、現在の `scene_id` に対応する `[scene.<scene_id>]` 節の `output.file` を取得してよい。

取得できた場合は、そのパスの拡張子を `.srt` に置き換えた値を通常の保存ダイアログの初期値として提案する。たとえば `output.file=C:\movie\sample.mp4` なら `C:\movie\sample.srt` を提案する。この値は候補にすぎず、保存先・ファイル名の強制、動画出力との連動、プロジェクトファイルの書き換えは行わない。

未保存プロジェクト、`output.file` 未設定、読取失敗、対応するシーン節がない場合は、既存の初期値または利用者が指定した保存先を使う。ディスク上の `.aup2` を読むため、保存後に書き出し先を変更してプロジェクトを未保存のままにしている場合は、最後に保存された値を候補にする。出力プラグイン固有の保存データや外部プラグインのファイルは調査しない。

出力範囲は、現行のシーン全体に加え、AviUtl2 のフレーム範囲選択を選べるようにする。手動の開始・終了フレーム指定は低優先度の将来項目とする。

フレーム範囲選択で出力する場合、範囲外の字幕は出力しない。範囲端にまたがる字幕は範囲内に切り詰め、範囲開始時刻を `00:00:00,000` とするよう全字幕時刻を再基準化する。番号は出力順に振り直す。統合、範囲による切り詰め、短字幕の結合・延長、オフセットの適用順は [4.2.4](#424-出力時刻範囲と最終化) に従う。

## 4.6 Exporter の UI 方針

Exporter は中級者以上が SRT 出力条件を指定する画面として、過度な装飾よりも対象範囲と処理結果を明確にする。対象を指定する操作は「出力対象」にまとめ、粒度が粗い順に次の三軸を並べる。

1. **対象時間範囲**：`シーン全体` または `フレーム範囲選択`。フレーム範囲選択では、その先頭を `00:00:00,000` として出力することを案内する。
2. **対象レイヤー**：`すべてのレイヤー` または `レイヤーを指定する`。指定時はレイヤー番号と完全一致のレイヤー名を使える。番号と名前の指定は合わせて適用し、両方に一致するレイヤーも一回だけ出力することを案内する。
3. **対象オブジェクト**：`テキスト`、`SRTrackObject`、`セリフ準備（PSDToolkit）` を個別に選ぶ。`SRTrackObject` の選択は、通常 Object と Standalone の両方を対象にする。

時間範囲、レイヤー、Object の順に対象を絞り込むことで、利用者がどの字幕を出力するかを段階的に理解できるようにする。

字幕時間の処理のうち、各字幕の長さを扱う `最小表示時間` は「字幕の整形」に置く。値は 0.500 秒以上、既定 1.000 秒であり、値未満の字幕は後続字幕へ結合し、末尾字幕だけは同じ値まで延長することを常時案内する。`出力時刻のオフセット` は完成した SRT 全体を前後へ移動する設定であるため、「出力対象」タブの最後に置く。秒数入力は小数点以下3桁のゼロ埋め表示（例：`0.000`、`1.000`）へ統一する。

保存ダイアログを開くボタンは、画面遷移を想起させる「次へ」ではなく、`保存先を選ぶ…` など保存先選択を明示する名称にする。

将来追加する同時開始字幕の順序設定は、候補を捨てる優先順位ではない。本文の結合順を決める設定として `同時開始時の並び順` と表記し、初期値を `上のレイヤーから（Layer 1 側）` とする。説明文には「同時に始まる字幕を結合する際の本文順」であることを記載する。

テキスト制御文字の変換設定は、仕様を定めたうえで「字幕の整形」に置く。装飾用制御文字・コメント・Lua スクリプトを削除する基本処理は設定にせず、ルビ・絵文字・待機／クリアだけを必要最小限のチェックボックスとして提供する。

### タブ構成

設定項目の増加で画面が縦に伸び続けないよう、Exporter は Windows 標準のタブコントロールで次の二画面へ分ける。

| タブ | 内容 |
| --- | --- |
| `出力対象` | 対象時間範囲、対象レイヤー、対象オブジェクト、出力時刻のオフセット |
| `字幕の整形` | 最小表示時間、将来の同時開始時の並び順、テキストの処理 |

`出力対象` は時間範囲だけでなくレイヤーと Object も指定するため、タブ名を「範囲指定」ではなく「出力対象」とする。このタブでは、対象時間範囲、対象レイヤー、対象オブジェクト、出力時刻のオフセットの順に並べる。保存先選択とキャンセルはタブの外に固定表示し、タブを切り替えても入力済みの値は保持する。保存先を選ぶ操作では、両タブの設定をまとめて検証する。

## 4.7 テキスト制御文字

AviUtl2 の公開テキスト仕様にある制御文字を対象に、SRT で表現できない見た目や実行結果をそのまま残さない。一般的な山括弧の文章を一括で削除せず、公式に定義された構文だけを認識して処理する。元の文章の校正・翻訳は行わない。

### 常に削除して無視するもの

次は設定の有無にかかわらず、SRT 本文から削除して無視する。

- 色、サイズ、フォント、文字装飾、プリセット、座標、字間・行間、文字変形などの装飾・レイアウト制御文字。
- コメント。
- Lua スクリプト制御文字。Exporter はスクリプトを実行せず、実行結果の文字列も再現しない。

設定画面には「装飾用の制御文字、コメント、Lua スクリプトは SRT 出力時に削除されます」と案内する。これらを含む Object ごとの警告は表示しない。

### ルビと絵文字

`字幕の整形` には次の独立したチェックボックスを置く。両方とも初期値はオンとする。

| チェックボックス | オン | オフ |
| --- | --- | --- |
| `ルビをカッコ書きで残す` | `</>漢字<!>かんじ</>` を `漢字（かんじ）` に変換する。 | ルビだけを削除し、親文字 `漢字` を残す。 |
| `絵文字をカッコ書きで残す` | `<&拍手>` を `（拍手）` に変換する。 | 絵文字を削除する。 |

### 時間制御

文字送り `<r>`、待機 `<w>`、表示クリア `<c>` は、初期実装では削除して無視する。本文は通常の Object 表示範囲で字幕候補にする。文字送りの再現は対象外とする。短い断片を大量に作る処理は最小表示時間による結合と相性が悪く、SRT の可読性も損ないやすいためである。

将来、待機と表示クリアだけを反映する実装を追加する場合は、`待機・クリアを反映` チェックボックスを `字幕の整形` に追加する。初期値はオフとし、オンの場合だけ `<w>` と `<c>` から字幕の開始・終了を分割する。`<r>` はこの設定でも再現しない。
