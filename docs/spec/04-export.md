# 4. 字幕ソースの統合と SRT 出力

## 4.1 字幕ソース

SRTrack Exporter は次の情報を共通形式へ正規化して後段へ渡す。

| 項目 | 内容 |
| --- | --- |
| 開始・終了 | シーン時刻上の字幕区間 |
| 本文 | 改行を保持した字幕文字列 |
| 出所 | 標準テキスト、PSDToolKit セリフ準備、SRTrack Object |
| レイヤー | 安定した並び順と利用者による選択に使用 |
| 元順序 | 同時刻・同一ソース時の安定した順序に使用 |

実装済みの対象は標準テキストと PSDToolKit のセリフ準備である。SRTrack Object は、オブジェクト識別・設定取得・SRT 解析・固定正速度での時間変換を実装中で、AviUtl2 上での検証後に対象として扱う。

## 4.2 現行エクスポーターの挙動

現行版では、対象レイヤーをシーン全体または番号・名前で選択し、標準テキストとセリフ準備を個別に選択できる。字幕を開始時刻順に並べ、最後以外の字幕の終了を次の字幕の開始に合わせる。短い字幕の結合、末尾の最小表示時間、全体オフセットを適用して SRT を出力する。

この規則は、元 SRT に含まれる意図的な空白区間・重複区間を変更する可能性がある。

## 4.3 SRT 由来の字幕の統合規則

SRTrack Object 由来の各 SRT 字幕は、時間変換後の開始時刻を持つ独立した字幕候補として扱う。標準テキスト、PSDToolKit のセリフ準備、SRT 由来の字幕を同じタイムラインへ開始時刻順に並べ、後から開始する候補は現在の字幕を中断する。

### 中断と次の SRT 字幕

- SRT 字幕 A の表示中に標準テキストまたはセリフ準備が開始した場合、A はその時点で終了する。
- 中断された A は、そのテキスト／セリフ準備が終わっても再開しない。字幕を二重に表示しないためである。
- 同じ SRT 内の次の字幕 B は、変換後の本来の開始時刻になったら開始する。B は、その時点で表示中のテキスト／セリフ準備を中断する。
- SRT 字幕自身の終了時刻は、その字幕が中断されずに表示中の場合に無字幕区間を作るための終了境界として扱う。

例として、SRT の A が 0〜5 秒、B が 5〜8 秒で、標準テキスト X が 2 秒に開始する場合、出力候補は `A: 0〜2 秒`、`X: 2〜5 秒`、`B: 5〜8 秒` となる。A は X の終了後にも再開しない。

中断により生じるごく短い字幕は、この段階では除外しない。統合後に既存の結合閾値、末尾最小表示時間、全体オフセット、開始前の区間の切り詰め・除外を適用する。

この統合規則は初期実装に反映済みである。AviUtl2 上で SRTrack Object を使った実機検証は未実施である。

次は未決定である。

- 同時刻に複数候補が始まる場合の優先順と本文の扱い。
- 複数の SRTrack Object が重複した場合の並び順・選択。
- 空本文、書式、制御文字をどう扱うか。

出力ファイルの番号は、最終的な出力順に 1 から付け直す案とする。0 秒以下の区間は出力しない。

## 4.4 出力ファイル

- 形式：SubRip（`.srt`）
- 文字コード：UTF-8
- 時刻表記：`HH:MM:SS,mmm`
- 見た目：フォント、色、座標、縁取りは出力しない

字幕の制御文字、ルビ、絵文字、スクリプト文字列の変換は未実装である。元の文章を黙って校正・翻訳しない。
