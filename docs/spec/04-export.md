# 4. 字幕ソースの統合と SRT 出力

## 4.1 字幕ソース

SRTrack Exporter は次の情報を共通形式へ正規化して後段へ渡す。

| 項目 | 内容 |
| --- | --- |
| 開始・終了 | シーン時刻上の字幕区間 |
| 本文 | 改行を保持した字幕文字列 |
| 出所 | 標準テキスト、対応する外部字幕準備オブジェクト、SRTrack Object、SRTrack Object (Standalone) |
| レイヤー | 安定した並び順と利用者による選択に使用 |
| 元順序 | 同時刻・同一ソース時の安定した順序に使用 |

現行実装は標準テキスト、対応する外部字幕準備 Object、`SRTrack Object` を対象とする。`SRTrack Object` は、Object 開始時に直上にある動画の `P`・`E`・速度・ループと自身の `D` を使う暫定実装である。Importer が生成するような、動画と同じ開始位置・長さで直上に置かれた Object を対象に概略確認している。

`SRTrack Object` と動画の開始位置が異なる場合の開始位置差、Object 範囲内での直上動画の切替、`SRTrack Object (Standalone)` の出力は未対応である。これらは SRT ソースの最終形として実装するが、現行版の対応範囲には含めない。

## 4.2 現行エクスポーターの挙動

現行版では、対象レイヤーをシーン全体または番号・名前で選択し、標準テキストとセリフ準備を個別に選択できる。字幕を開始時刻順に並べ、最後以外の字幕の終了を次の字幕の開始に合わせる。短い字幕の結合、末尾の最小表示時間、全体オフセットを適用して SRT を出力する。

この規則は、元 SRT に含まれる意図的な空白区間・重複区間を変更する可能性がある。

## 4.3 SRT 由来の字幕の統合規則

SRTrack Object と SRTrack Object (Standalone) 由来の各 SRT 字幕は、時間変換後の開始時刻を持つ独立した字幕候補として扱う。標準テキスト、対応する外部字幕準備オブジェクト、SRT 由来の字幕を同じタイムラインへ開始時刻順に並べ、後から開始する候補は現在の字幕を中断する。

### 中断と次の SRT 字幕

- SRT 字幕 A の表示中に標準テキストまたはセリフ準備が開始した場合、A はその時点で終了する。
- 中断された A は、そのテキスト／セリフ準備が終わっても再開しない。字幕を二重に表示しないためである。
- 同じ SRT 内の次の字幕 B は、変換後の本来の開始時刻になったら開始する。B は、その時点で表示中のテキスト／セリフ準備を中断する。
- SRT 字幕自身の終了時刻は、その字幕が中断されずに表示中の場合に無字幕区間を作るための終了境界として扱う。

例として、SRT の A が 0〜5 秒、B が 5〜8 秒で、標準テキスト X が 2 秒に開始する場合、出力候補は `A: 0〜2 秒`、`X: 2〜5 秒`、`B: 5〜8 秒` となる。A は X の終了後にも再開しない。

中断により生じるごく短い字幕は、この段階では除外しない。統合後に既存の結合閾値、末尾最小表示時間、全体オフセット、開始前の区間の切り詰め・除外を適用する。

この統合規則は標準テキスト、セリフ準備、および現行対応範囲の SRTrack Object に適用する。直上動画参照の完全化と Standalone への適用は後続開発事項とする。

次は未決定である。

- 同時刻に複数候補が始まる場合の優先順と本文の扱い。
- 複数の SRTrack Object／SRTrack Object (Standalone) が重複した場合の並び順・選択。
- 空本文、書式、制御文字をどう扱うか。

出力ファイルの番号は、最終的な出力順に 1 から付け直す案とする。0 秒以下の区間は出力しない。

## 4.4 出力ファイル

- 形式：SubRip（`.srt`）
- 文字コード：UTF-8
- 時刻表記：`HH:MM:SS,mmm`
- 見た目：フォント、色、座標、縁取りは出力しない

字幕の制御文字、ルビ、絵文字、スクリプト文字列の変換は未実装である。元の文章を黙って校正・翻訳しない。

## 4.5 保存先と動画書き出し範囲への配慮

SRTrack Exporter は、あくまで SRT を保存する通常のエクスポーターである。動画ファイルの書き出し、動画出力プラグインの操作、動画出力の成功・失敗・キャンセルとの連動は行わない。

SRT の保存時は通常の保存ダイアログを表示する。同名保存を強制せず、既存ファイルの上書き確認も OS の保存ダイアログに委ねる。

現行の Plugin SDK には、動画の書き出し先を直接取得する API はない。一方、保存済みの AviUtl2 プロジェクト（`.aup2`）はシーンごとに標準の `output.file` を記録する。Exporter は、SDK で取得した保存済みプロジェクトのパスを**読み取り専用**で開き、現在の `scene_id` に対応する `[scene.<scene_id>]` 節の `output.file` を取得してよい。

取得できた場合は、そのパスの拡張子を `.srt` に置き換えた値を通常の保存ダイアログの初期値として提案する。たとえば `output.file=C:\movie\sample.mp4` なら `C:\movie\sample.srt` を提案する。この値は候補にすぎず、保存先・ファイル名の強制、動画出力との連動、プロジェクトファイルの書き換えは行わない。

未保存プロジェクト、`output.file` 未設定、読取失敗、対応するシーン節がない場合は、既存の初期値または利用者が指定した保存先を使う。ディスク上の `.aup2` を読むため、保存後に書き出し先を変更してプロジェクトを未保存のままにしている場合は、最後に保存された値を候補にする。出力プラグイン固有の保存データや外部プラグインのファイルは調査しない。

出力範囲は次の段階で実装する。

1. 現行のシーン全体出力を維持する。
2. タイムラインのフレーム選択範囲を出力範囲として選べるようにする。
3. 手動の開始・終了フレーム指定は低優先度の将来項目とする。

選択範囲で出力する場合、範囲外の字幕は出力しない。範囲端にまたがる字幕は範囲内に切り詰め、範囲開始時刻を `00:00:00,000` とするよう全字幕時刻を再基準化する。番号は出力順に振り直す。オフセットなど他の出力設定との適用順は、それらの実装を見直す段階で別途定める。
