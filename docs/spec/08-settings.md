# 8. SRTrack 設定

## 8.1 目的と初期範囲

SRTrack Importer は外部の入力プラグインと同じファイルドロップ経路を利用する。そのため、利用者が Importer の二つの入口を個別に停止し、SRTrack をドロップ処理から完全に外せる退避経路を設ける。

現行の設定画面は `SRTrack 設定…` とする。現時点の設定項目は Importer のものだけだが、Exporter を含む共通診断ログの閲覧入口でもある。Exporter や Object の出力条件は、この画面ではなく Exporter の実行時画面で指定する。

## 8.2 設定項目

```text
[✓] 動画ファイルドロップ時、同名の SRT ファイルがあれば読み込む

[✓] SRT ファイルドロップ時、次の Object として読み込む
    ○ SRTrack Object
    ○ SRTrack Object (fix)
```

既定値は、動画の同名 SRT 自動取込を有効、SRT 単体取込を有効、Object 種別を `SRTrack Object` とする。`SRTrack Object (fix)` は選択肢として提供するが、初期の既定にはしない。`SRTrack Object (txt)` は SRT を入力にしないため、この設定の選択肢に含めない。

SRT 単体取込のチェックが無効な場合、Object 種別の選択肢は無効表示とする。

## 8.3 二つの独立した取込経路

動画の同名 SRT 自動取込と SRT 単体取込は、設定・登録・処理をそれぞれ独立させる。

| 入口 | 有効時の処理 | 無効時の処理 |
| --- | --- | --- |
| 動画ファイル | GCMZDrops2 の Lua ハンドラーを登録し、同名 SRT がある動画だけを動画＋`SRTrack Object` の複数 Object エイリアスへ置換する。 | Lua ハンドラーを登録しない。SRTrack は動画のドロップ処理に関与しない。 |
| SRT ファイル | AviUtl2 SDK の `.srt` 専用ドロップハンドラーを登録し、選択された Object を直接配置する。 | `.srt` ドロップハンドラーを登録しない。他プラグインまたは AviUtl2 の処理を妨げない。 |

動画ペア取込は、設定にかかわらず常に `SRTrack Object` を使う。選択された Object 種別は SRT 単体取込にだけ適用する。

両方を無効にした次回起動時、SRTrack Importer は GCMZDrops2 の Lua ハンドラーも AviUtl2 の SRT ドロップハンドラーも登録しない。したがって、SRTrack はファイルドロップに関与しない。

## 8.4 適用タイミング

Lua ハンドラーと AviUtl2 のファイルドロップハンドラーは起動時に登録され、登録解除用の公式 API はない。このため、設定画面で保存した値は次回の AviUtl2 起動時に読み込んで登録可否を決定する。

設定画面には次の案内を常設する。

> 取込設定の変更は、AviUtl2 を再起動した後のファイルドロップから反映されます。

保存直後の現在の起動中セッションでは、保存前の登録状態を維持する。設定変更によって、編集中のドロップ経路を途中で変更しない。

## 8.5 実装上の安全条件

- 設定値の読出しに失敗した場合は既定値を使用する。
- 動画ペア取込が有効でも、ペア化に失敗した場合は元のドロップファイル一覧を変更しない。
- SRT 単体取込は動画取込の Lua ハンドラーを使用せず、SDK の直接 Object 作成だけを使用する。
- 設定画面・設定保存の失敗が、既に登録済みの動画または SRT のドロップ処理を妨げてはならない。

## 8.6 診断ログ

SRTrack 設定パネルには、「診断ログ」領域を設ける。これは Importer 専用のログではなく、初期実装で共通ログへ記録するExporter、SRT単体Importer、動画ペア取込ハンドラー登録結果の閲覧入口である。

- Importer はドロップを妨げないため、失敗してもモーダルを表示せず、この領域から後で受理・委譲・失敗段階を確認する。
- Exporter は警告・エラーを出力後のモーダルでも表示し、同じ内容を診断ログへ残す。
- 初期実装では全件を表示し、全件を Issue 報告向けにコピーまたは消去できる。機能・重要度での絞り込みや選択項目だけのコピーは将来の改善項目とする。
- 初期実装では一定件数だけメモリに保持し、AviUtl2 終了時に破棄する。ログの自動ファイル保存、外部送信、絶対パスや字幕本文の記録は行わない。

初期実装で表示するのは Exporter、SRT 単体 Importer、動画ペア取込ハンドラーの登録結果である。Preview と GCMZDrops2 のLua動画ハンドラーの実行時詳細は、公開された安全な共有経路を追加できるまで診断ログへ含めない。

ログ項目、エラーコード、プライバシー方針は [05-errors-and-validation.md](05-errors-and-validation.md) を正とする。
