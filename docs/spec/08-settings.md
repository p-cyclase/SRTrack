# 8. SRTrack 共通設定

## 8.1 役割

`SRTrack.aux2` は将来 AviUtl2 の設定メニューに `SRTrack 設定…` を登録する。これは Exporter の出力ごとの設定や Object ごとの設定とは別の、SRTrack 全体に適用する利用者単位のプロパティである。設定値は既存の SRTrack 設定と同じ保存先へ記録し、プロジェクトファイルや Object の内容を変更しない。

設定値の保存・Lua ハンドラーへの読出し基盤は実装するが、設定ウィンドウは未実装である。UI 実装までは既定値が使われる。

設定画面は、Importer が想定外の環境・他の入力プラグインとの組合せで問題を起こした場合に、利用者が SRTrack を停止して通常の動画編集を続けられる退避経路でもある。

## 8.2 現在の設定項目

| 項目 | 値 | 既定値 | 効果 |
| --- | --- | --- | --- |
| 同名 SRT 自動取込 | オン／オフ | オン | オフのとき Importer は動画ドロップへ介入せず、元のファイルを通常の入力プラグインへ渡す。 |
| SRT ファイル単体のドロップ | `SRTrack Object`／`SRTrack Object (Standalone)`／`処理しない` | 処理しない | `.srt` だけをドロップしたときの Importer の扱いを選ぶ。 |

Importer が内部で失敗した場合に元ファイルを変更せず通常読込へ委譲する安全フォールバックは、利用者が無効にできない原則とする。設定項目にはしない。

## 8.3 反映時期

設定画面の実装後、設定変更は保存直後から次のドロップに反映する。Lua ハンドラーはドロップ処理の開始時に SRTrack.aux2 が提供する現在の設定値を参照する。再起動は要求しない。

## 8.4 設定の境界

グループ化、動画全長 `D` の初期設定、同名 SRT の探索規則は、現在は同名 SRT 自動取込が有効な場合の一体の処理である。個別のオン・オフは設けない。これらは Object の配置後に利用者が編集でき、部分的に無効化すると不完全なペアを生成するおそれがあるためである。

将来 Importer の独立した機能が増えた場合だけ、利用者に意味のある単位で設定項目を追加する。内部実装上の細部をそのまま設定として露出しない。
