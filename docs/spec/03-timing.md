# 3. 時間変換と動画参照

## 3.1 共通原則

フレームレートは有理数 `rate / scale` とし、フレーム `n` の時刻は `n × scale / rate` 秒で扱う。途中で繰り返しフレーム丸めを行わず、可能な限り整数ミリ秒または有理数で計算して最後に丸める。速度 0、逆再生、可変速度、中間点、時間制御、シーンをまたぐ利用は初期対象外である。

## 3.2 SRTrack Object

SRTrack Object の字幕変換は、Object の存在範囲と直上動画の存在範囲の交差区間ごとに行う。直上動画のタイムライン開始時刻を `A`、再生位置を `P`、再生速度を百分率から換算した倍率を `v`、シーン時刻を `T` とすると、SRT 元時刻 `s` は次で表す。

```text
s = P + v × (T - A)
```

有効区間は、SRTrack Object の範囲、直上動画の存在範囲、および非ループ時の `E` までの再生範囲の交差とする。直上動画がなくなった時点で、その区間の字幕は終了する。直上動画が再出現した場合は、その動画の `A`・`P`・速度を使う別の区間として字幕変換を再開する。直上動画がない区間には字幕を出力しない。

ループ時は SRTrack Object が保持する `D` を周期に使い、`s = (P + v × (T - A)) mod D` とする。`D <= 0` はループ時だけ無効であり、Preview は診断を表示し、Exporter はそのループ区間を字幕なしとして扱う。

この方式が標準動画の分割・伸縮・速度変更・ループ時の時刻と完全に一致するかは未検証である。実装後に標準動画と比較し、不一致があれば対応範囲または変換規則を明記する。

Preview はこの式を使う。Lua API から SRTrack Object と直上動画の開始フレーム、およびフレームレートを取得し、`T - A` を `((SRTrack Object の開始フレーム - 動画の開始フレーム) / フレームレート) + obj.time` として計算する。Exporter も同じ式と有効区間を使う。したがって、同じ動画の途中から SRTrack Object を置いた場合も、開始位置差を反映し、各 Object 単独の字幕時刻は Preview と Exporter で一致する。

## 3.3 SRTrack Object (Standalone)

SRTrack Object (Standalone) の開始時刻を `A`、保持する再生開始位置を `P`、速度倍率を `v` とすると、`s = P + v × (T - A)` である。SRT の最終字幕以降は空表示とし、Object 自身のタイムライン範囲外には出力しない。ループと `D` は使わない。Exporter はこの式を使い、Standalone を `SRTrack Object` と同じ対象設定で字幕ソースとして扱う。

## 3.4 グループ化

グループ化は時間変換の入力ではない。Importer が動画と SRTrack Object を同じ開始・長さで上下二層へ配置し、グループ化することで、通常の移動・分割・伸縮操作が両者へ行われやすくする。参照時は常に直上レイヤーの動画を読むため、グループ ID の列挙や常駐同期は要求しない。
