# 3. 時間変換と動画参照

## 3.1 共通原則

フレームレートは有理数 `rate / scale` とし、フレーム `n` の時刻は `n × scale / rate` 秒で扱う。途中で繰り返しフレーム丸めを行わず、可能な限り整数ミリ秒または有理数で計算して最後に丸める。速度 0、逆再生、可変速度、中間点、シーンをまたぐ利用は初期対象外である。標準テキストの時間制御文字は Exporter の候補生成として対応し、その規則は [04-export.md](04-export.md) に定める。SRTrack Object 自体の時間変換は本章の規則だけを使う。

## 3.2 SRTrack Object

SRTrack Object の字幕変換は、Object の存在範囲と上側の直前動画Objectの存在範囲の交差区間ごとに行う。上側の直前動画Objectとは、各時刻でSRTrack ObjectよりLayer 1側を順に見て最初に見つかる標準 `動画ファイル` Objectである。動画以外のObjectは読み飛ばし、SRTrack Objectより下側は探索しない。動画 Object のタイムライン開始時刻を `A`、再生位置を `P`、再生速度を百分率から換算した倍率を `v`、シーン時刻を `T` とすると、SRT 元時刻 `s` は次で表す。

```text
s = P + v × (T - A)
```

有効区間は、SRTrack Object の範囲と上側の直前動画Objectのタイムライン上の存在範囲の交差とする。参照動画がなくなった時点で、その区間の字幕は終了する。上側に動画が再出現した場合、またはより近い上側動画へ切り替わった場合は、その動画の `A`・`P`・速度を使う別の区間として字幕変換を再開する。動画がない区間には字幕を出力しない。

標準動画 Object の UI は再生範囲の終端も表示するが、現行の Object／Preview と Exporter が共通して取得できる値は再生位置 `P`、速度、ループ、およびタイムライン上の存在範囲である。そのため、非ループ時に UI 上の再生範囲終端だけを別途判定する処理は初期版の対象外とする。これは Preview と Exporter の一致を優先するためである。

ループ時は SRTrack Object が保持する `D` を周期に使い、`s = (P + v × (T - A)) mod D` とする。`D <= 0` はループ時だけ無効であり、Preview は診断を表示し、Exporter はそのループ区間を字幕なしとして扱う。

この方式が標準動画の分割・伸縮・速度変更・ループ時の時刻と完全に一致するかは未検証である。実装後に標準動画と比較し、不一致があれば対応範囲または変換規則を明記する。

Preview はこの式を使う。Lua APIからSRTrack Objectと上側の直前動画Objectの開始フレーム、およびフレームレートを取得し、`T - A` を `((SRTrack Object の開始フレーム - 動画の開始フレーム) / フレームレート) + obj.time` として計算する。Exporterも同じ探索規則・式、動画の再生位置・速度・ループ、および有効区間を使う。したがって、同じ動画の途中からSRTrack Objectを置いた場合も、開始位置差を反映し、各 Object 単独の字幕時刻はPreviewとExporterで一致する。

## 3.3 SRTrack Object (fix)

SRTrack Object (fix) の開始時刻を `A`、保持する再生開始位置を `P`、速度倍率を `v`、全長を `D` とする。ループ再生がオフの場合、SRT 元時刻 `s` は `s = P + v × (T - A)` である。SRT の最終字幕以降は空表示とし、Object 自身のタイムライン範囲外には出力しない。

ループ再生がオンの場合は、`D > 0` を周期に使い、`s = (P + v × (T - A)) mod D` とする。`D` は動画を参照しない `fix` 型では、必ずしも動画ファイルの長さを表さない。ループの一周期としてユーザーが設定する値である。`D <= 0` はループ時だけ無効であり、Preview は診断を表示し、Exporter はその Object だけを字幕なしとして処理を継続する。

Exporter はこの式を使い、`fix` 型を `SRTrack Object` と同じ対象設定で字幕ソースとして扱う。Preview と Exporter は、ループを含めて同じ時間変換規則を用いる。

## 3.4 SRTrack Object (txt)

SRTrack Object (txt) は時間変換を行わない。Object の開始時刻を `A`、終了時刻を `B` とすると、空でない入力テキストの候補区間は `[A, B)` である。Preview はこの区間だけ入力テキストを表示し、Exporter は同じ区間を一つの字幕候補として統合処理へ渡す。

## 3.5 グループ化

グループ化は時間変換の入力ではない。Importer が同じ時刻の隣接する2レイヤーに、上側（Layer 1 側）へ動画、下側へ SRTrack Object を同じ開始・長さで配置し、グループ化することで、通常の移動・分割・伸縮操作が両者へ行われやすくする。フィルタなどを両者の間へ追加しても、参照時は上側の直前動画Objectを読む。グループ ID の列挙や常駐同期は要求しない。
