# 3. 時間変換と編集同期

## 3.1 初期版の変換モデル

固定の正の速度、ループなしの場合、シーン時刻 `T` と SRT 元時刻 `s` の関係は次のとおりとする。

```text
t = T - A
s = P + v × t
T = A + (s - P) / v
```

`A` はオブジェクト開始時刻、`P` は再生開始位置、`v` は再生速度である。`v = 1` は等速、`v = 2` は 2 倍速、`v = 0.5` は半速を表す。

エクスポート時は、各 SRT 区間をオブジェクトが実際に参照する SRT 範囲と交差させる。交差した両端を `T` に変換し、オブジェクトのシーン上の範囲で切り詰める。交差が空なら出力しない。

## 3.2 フレームと丸め

プロジェクトのフレームレートは有理数 `rate / scale` として扱う。フレーム `n` の時刻は `n × scale / rate` 秒であり、SRT の `m` ミリ秒に対応する理論上のフレーム位置は `m × rate / (1000 × scale)` である。

途中でフレームへ繰り返し丸めず、可能な限り整数ミリ秒または有理数で計算して最後に丸める。29.97 fps 系を含む分数フレームレートで、丸め方向と許容誤差を検証する。

## 3.3 編集への追従

次のどの方式を採用するかは未決定である。

1. **手動同期**：動画と SRTrack Object の位置・範囲・速度を利用者が合わせる。
2. **編集操作の連動**：グループ化などで移動・分割を一緒に行う。
3. **動画設定の参照**：対象動画を指定し、必要な設定を読み込んで反映する。

初期版の実装対象を決めるまで、標準動画と同じ挙動を保証しない。特に分割、端の変更、再生開始位置、速度変更を、対象 AviUtl2 版で標準動画と比較する。

## 3.4 初期版の対象外

速度 0、逆再生、ループ、可変速度、中間点、時間制御、シーンをまたぐ利用は初期版では対象外である。対応を追加する場合、上記の線形変換式をそのまま適用してはならない。
