# 1. 目的・構成・利用の流れ

## 1.1 目的

SRTrack は、AviUtl2 のタイムラインで管理する字幕情報を SRT として出力するツールキットである。音声認識、翻訳、動画への字幕焼き込み、動画サイトへのアップロードは行わない。

編集前から SRT を持っている場合も、動画の位置、長さ、再生開始位置、速度に合わせて字幕を再出力できるようにする。

## 1.2 構成

### SRTrack Exporter（実装済み）

汎用プラグイン（`.aux2`）として、現在のシーンの対象レイヤーから字幕候補を集め、時刻を整理して SRT を保存する。

現行の読取り対象は次のとおり。

- 標準の「テキスト」オブジェクト
- PSDToolKit の「セリフ準備@PSDToolKit」
- SRTrack Object

### SRTrack Object（実装中）

SRT ファイルと再生に関する設定をタイムライン上に保持するカスタムオブジェクトである。エクスポーターがこのオブジェクトの配置範囲と設定を読み、SRT 由来の字幕を出力用データへ変換する。

編集時の補助として、SRT 由来の現在字幕だけを画面に描画するプレビューを切り替え可能にする。これは確認専用で、ファイル出力中は描画せず、動画へ焼き込まれない。SRTrack Exporter がテキスト等と統合した最終 SRT の表示ではない。

PSDToolKit の「セリフ準備」は、タイムライン上に字幕関連の情報を保持し、表示側とは分離する先例として参考にする。ただし SRTrack は PSDToolKit の設定名や実装へ依存しない。

より重要な先例は操作モデルである。PSDToolKit2 では、音声ファイルと対応するセリフ準備を生成・グループ化し、編集操作に同期させる。SRTrack は、動画ファイルと対応する SRTrack Object の組で同じ考え方を採用する。

## 1.3 基本の利用の流れ

1. 動画と対応する SRT を用意する。
2. SRTrack Object をタイムラインに配置し、SRT と再生設定を指定する。
3. 動画の利用範囲・再生開始位置・速度に合わせ、読み込みオブジェクトを調整する。
4. 必要なら標準テキストや PSDToolKit のセリフ準備と併用する。
5. SRTrack Exporter で対象レイヤーと対象ソースを選び、編集後の時刻に対応する SRT を出力する。

初期版で実現を目指す生成手順は、動画ファイルをタイムラインへドロップしたときに、同名の SRT を参照する SRTrack Object を同時に作成し、動画オブジェクトとグループ化するものである。現時点では SRTrack Object を手動配置して使う段階であり、自動生成・グループ化は未実装である。SRT が見つからない場合や複数候補がある場合の扱いは別途決める。

## 1.4 用語

| 用語 | 意味 |
| --- | --- |
| シーン時刻 `T` | 出力先タイムラインの基準時刻 |
| オブジェクト開始時刻 `A` | 読み込みオブジェクトが配置されたシーン時刻 |
| オブジェクト内時刻 `t` | 読み込みオブジェクト開始からの経過時間 |
| SRT 元時刻 `s` | SRT ファイルに書かれた時刻 |
| 再生位置 `P` | オブジェクト開始時に参照する SRT 元時刻。UI は秒単位 |
| 再生速度 | UI は百分率。内部倍率 `v = 再生速度 ÷ 100` |

## 1.5 初期版の対象外

- 動画と同名の SRT の自動検出
- 速度 0、逆再生、ループ、可変速度
- 動画編集操作への完全自動追従
- 複数 SRT の重複を自動的に解決する機能
