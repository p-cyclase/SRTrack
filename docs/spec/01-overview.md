# 1. 目的・構成・利用の流れ

## 1.1 目的

SRTrack は、AviUtl2 のタイムラインで管理する字幕情報を SRT として出力するツールキットである。音声認識、翻訳、動画への字幕焼き込み、動画サイトへのアップロードは行わない。

編集前から SRT を持っている場合も、動画の位置、長さ、再生開始位置、速度に合わせて字幕を再出力できるようにする。

## 1.2 構成

### SRTrack Exporter（実装済み）

汎用プラグイン（`.aux2`）として、現在のシーンの対象レイヤーから字幕候補を集め、時刻を整理して SRT を保存する。

現行の読取り対象は次のとおり。

- 標準の「テキスト」オブジェクト
- 対応する外部字幕準備オブジェクト
- SRTrack Object

### SRTrack Object（実装中）

SRT ファイルと再生に関する設定をタイムライン上に保持するカスタムオブジェクトである。エクスポーターがこのオブジェクトの配置範囲と設定を読み、SRT 由来の字幕を出力用データへ変換する。

編集時の補助として、SRT 由来の現在字幕だけを画面に描画するプレビューを切り替え可能にする。これは確認専用で、ファイル出力中は描画せず、動画へ焼き込まれない。SRTrack Exporter がテキスト等と統合した最終 SRT の表示ではない。

SRTrack は特定の外部字幕ツールの設定名や実装へ依存しない。動画ファイルと対応する SRTrack Object を一組として扱い、編集操作の結果を同期させることを目標とする。

### SRTrack Importer（GCMZDrops2 連携）

GCMZDrops2 の公開ハンドラースクリプト API を利用し、動画ファイルの通常読込に介入せず、同名 SRT がある場合だけ SRTrack Object 用の Object データを追加する。対象は、利用者の L-SMASH Works の入力プラグイン設定に登録済みで動画トラックを持つ拡張子と、標準 AVI 読込の `.avi` である。動画は最終ファイルリストに残るため、L-SMASH Works または標準 AVI 読込が従来どおり動画を読み込む。動画と SRTrack Object は一組として、動画を置ける区間とその直下に Object を置ける区間がそろう最初の後方時刻へ配置してグループ化する。既存オブジェクトは動かさない。同名 SRT がない場合は、動画だけを通常どおり配置し、通知を表示しない。Importer は動画の総時間を Object の再生範囲終端として初期化し、動画と SRT の初期対応づけを担う。分割・伸縮後に `P` と終端 `E` を動画と同じ規則で変化させる責務は SRTrack Object 側にある。詳細は [06-importer.md](06-importer.md) を参照する。

## 1.3 基本の利用の流れ

1. 動画と、同名の対応 SRT を同じフォルダに用意する。
2. SRTrack Importer で動画をタイムラインに配置する。SRT が見つかった場合は、動画と対応する SRTrack Object の二段分を置ける最初の後方時刻に、両者が作成・グループ化される。
3. 動画の利用範囲・再生開始位置・速度に合わせ、SRTrack Object が SRT の参照範囲を保持する。
4. 必要なら標準テキストや対応する外部字幕準備オブジェクトと併用する。
5. SRTrack Exporter で対象レイヤーと対象ソースを選び、編集後の時刻に対応する SRT を出力する。

Importer 未導入時や同名 SRT がない場合は、従来どおり SRTrack Object を手動配置して使える。初期実装は GCMZDrops2 経由のファイルドロップだけを対象とし、実機連携は未検証である。SRT が見つからない場合や複数候補がある場合の扱いは別途決める。

## 1.4 用語

| 用語 | 意味 |
| --- | --- |
| シーン時刻 `T` | 出力先タイムラインの基準時刻 |
| オブジェクト開始時刻 `A` | 読み込みオブジェクトが配置されたシーン時刻 |
| オブジェクト内時刻 `t` | 読み込みオブジェクト開始からの経過時間 |
| SRT 元時刻 `s` | SRT ファイルに書かれた時刻 |
| 再生位置 `P` | オブジェクト開始時に参照する SRT 元時刻。UI は秒単位 |
| 再生範囲終端 `E` | オブジェクトが参照する SRT 元時刻の終端。動画由来の秒単位 |
| 再生速度 | UI は百分率。内部倍率 `v = 再生速度 ÷ 100` |
| 動画全長 `D` | Importer が取込時に取得する元動画全体の長さ。移動・分割・伸縮では変化せず、将来のループ処理だけに用いる |

## 1.5 初期版の対象外

- 速度 0、逆再生、ループ、可変速度
- 複数 SRT の重複を自動的に解決する機能

SRTrack Importer の初期実装はあるが、GCMZDrops2 経由の実機連携は未検証である。移動・分割・伸縮への自動追従は未実装である。
