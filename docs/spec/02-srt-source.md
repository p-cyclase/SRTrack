# 2. SRTrack Object と入力データ

> **初期版の Object 構成**：`SRTrack Object`、`SRTrack Object (fix)`、`SRTrack Object (txt)` の三種を提供する。`fix` 型と `txt` 型は初期版で実装済みである。
>
> **実装済みの拡張**：通常 Object の `動画全長` は `全長` へ改称した。`fix` 型にも `全長` とループ再生を追加し、動画 Object を参照しない点以外の時間変換機能を通常 Object と揃えた。

## 2.1 三つの Object

SRTrack は、動画追従、独立した SRT、個別テキストを別の Object として扱う。`SRTrack Object` を主用途とし、`fix` と `txt` は補助的な Object と定義する。

| Object | 時間変換の基準 | 主な用途 | 状態 |
| --- | --- | --- | --- |
| SRTrack Object | 同じ時刻に自身よりLayer 1側で最も近い標準 `動画ファイル` Object | レンダリング済み動画と対応する SRT | `SRTrackObject.obj2`、初期版完成 |
| SRTrack Object (fix) | Object 自身の再生開始位置・速度・ループ再生 | 動画と独立した SRT の配置 | `SRTrackObject(fix).obj2`、初期版完成 |
| SRTrack Object (txt) | Object 自身のタイムライン範囲 | SRT にだけ出力する補足・個別字幕 | `SRTrackObject(txt).obj2`、初期版完成 |

`SRTrack Object` と `SRTrack Object (fix)` は SRT ファイルを読み、`SRTrack Object (txt)` は自由入力テキストを読む。三者とも Exporter の字幕ソースになり、編集用字幕プレビューを任意に表示する。プレビューは確認専用であり、動画書き出し中は描画しない。標準テキスト等との統合・結合・オフセット後の最終 SRT と Preview 表示の一致は要件にしないが、各 Object が単独で変換する字幕時刻は Exporter と Preview で実用上の一致を目指す。通常 Object の動画再生速度に中間点がある場合も、2.2.1 の区間ごとの一定速度近似を両者へ実装する。フレームレートの表現差による微小な丸め差は許容する。

## 2.2 SRTrack Object

SRTrack Object は動画に付随する主用途の字幕側 Object である。保持する項目は `SRT ファイル`、`全長 D`、`字幕プレビュー` とする。`D` は画面へ表示し、Importer が初回配置時に元動画の全長として設定する。取得不能時は `0` を設定する。`D` はループの周期だけに使い、移動・分割・伸縮では変更しない。AviUtl2 の UI 上で手動変更できる場合は動画との整合性が崩れうるため、変更は非推奨とする。

再生位置 `P`、再生速度、ループ再生は SRTrack Object に保存しない。Object が存在する各時刻で、自身よりLayer 1側を順に探索し、最初に見つかる標準 `動画ファイル` Object の現在値を直接参照する。動画以外のObjectは読み飛ばし、SRTrack Objectより下側のObjectは参照しない。有効区間の終端は、参照動画 Object がタイムライン上に存在する終端とする。動画と SRTrack Object をグループ化することは、移動・分割・伸縮時にこの上下関係を保ちやすくする補助であり、参照の成立条件ではない。

### 2.2.1 動画 Object の中間点を含む時間変換

動画 Object の再生速度に中間点がある場合、Object 全体の先頭で取得した速度を使い続けない。動画 Object の開始・各中間点・終端で区間を分け、各区間の先頭で取得した再生速度を区間内で一定として、再生位置 `P` から順に積算する。これは速度曲線そのものを積分・完全再現する仕様ではなく、中間点区間ごとの一定速度近似である。

Exporter は公開 SDK の Object 区間・トラック値 API を使ってこの規則を実装済みである。Preview も `SRTrack.mod2` を介し、Lua から渡された現在レイヤー・シーンフレームを基に上側の参照動画を探索してソース時刻を求める。モジュール側では Exporter と同じ公開 API により、参照動画の区間境界と各区間先頭の再生速度を取得する。Lua Object はこのソース時刻だけを使って SRT の表示対象を決める。

中間点をまたぐ一つの SRT 字幕は、Preview では一つの連続した字幕として表示する。区間境界を字幕の表示上の区切りにはしない。上側の参照動画が切り替わる、動画がない、ループ設定が不正である場合の既存の扱いは変更しない。

`SRT ファイル` は利用者が指定する独立した参照である。Importer は同名 SRT を初期値として設定するだけで、動画ファイルの変更後に SRT パスを自動追従・差し戻ししない。別名の動画と SRT を組み合わせる手動利用を妨げない。

## 2.3 SRTrack Object (fix)

SRTrack Object (fix) は動画を参照しない補助的な Object である。`SRT ファイル`、再生開始位置 `P`、再生速度、ループ再生、`全長 D`、`字幕プレビュー` と Object 自身のタイムライン範囲を保持する。動画 Object を参照しない点以外の時間変換機能は、SRTrack Object と同等とする。

ループ再生がオフなら、現在の再生位置と速度から SRT 時刻を一方向に変換する。オンなら、正の `全長 D` を周期として SRT 時刻を先頭へ折り返す。`D` は動画の長さに限らず、ループの周期を表す値である。ループ再生時に `D` が `0` または取得不能なら、Preview は「ループ再生には全長が必要です」と表示し、Exporter は該当 Object を除外して他の出力を継続する。動画とのグループ関係は持たない。SRT の最終字幕を過ぎた後は、非ループ時には Preview を表示せず、途中で終了したい場合は Object の終端を使う。Exporter も `SRTrack Object` と同じ対象設定で `fix` 型を字幕ソースとして扱う。

## 2.4 SRTrack Object (txt)

SRTrack Object (txt) は、`テキスト` と `字幕プレビュー` だけを持つ補助的な Object である。動画、SRT ファイル、再生位置、再生速度、全長、ループ、グループ関係は持たない。Object の開始から終了まで、入力テキストを一つの字幕候補として扱う。空テキストは字幕候補を生成しない。

Preview は通常の SRTrack Object と同じ描画経路と座標系を使う。利用者が Object の座標を動かすと、編集画面の Preview も同じ位置へ動く。動画書き出し中は描画しない。Exporter は `txt` 型を SRTrack Object 群の対象設定に含め、Object 範囲をそのまま字幕区間として出力する。

## 2.5 将来の Object 種別変換

右クリックメニューからの Object 種別変換は将来構想であり、現段階では実装しない。少なくとも、標準 `SRTrack Object` を `fix` 型へ固定する操作と、SRT 内の字幕を `txt` 型の個別 Object へ分割する操作を検討対象とする。変換時の SRT パス、時間変換、座標、既存 Object の置換・複製の詳細は別途仕様化する。

## 2.6 SRTrack Object の参照失敗とプレビュー

SRTrack Object の存在する時刻に、上側のレイヤー群から標準動画を見つけられない場合、その時刻は有効な字幕ソースではない。Preview は編集画面に専用メッセージを表示する。Exporter は当該区間を単に字幕がない区間として扱い、警告や失敗にせず出力を継続する。SRT の読込失敗や不正な設定も、空字幕として黙って扱わず編集画面に診断を表示する。診断は動画書き出し中には描画しない。

### Preview の表示分類

Preview は最終的な動画テロップや SRT 出力ではなく、編集時の補助表示であることを明示する。`SRTrack Object`、`SRTrack Object (fix)`、`SRTrack Object (txt)` の三種で、空でない通常 Preview の本文には共通して `[SRTrack] ` を付ける。接頭辞は動画書き出しと Exporter の SRT 出力には含めない。

Preview の画面内メッセージは共通診断ログとは別の局所的な表示であり、現在の Object の Preview 可否だけを表す。動画レンダリングや Exporter 全体を停止させない。画面内の表示は次の三段階に分ける。

| 分類 | 主な条件 | 表示の意図 |
| --- | --- | --- |
| 注意 | 通常 Object の上側に参照可能な動画 Object がない | 想定内の参照なしを知らせる。Exporter では該当区間を出力しない正常条件である。 |
| 設定を確認 | SRT ファイル未指定、fix の再生速度不正、ループ再生中の全長不足 | 現在の Object の設定を修正すれば Preview できることを示す。 |
| 読み込みに失敗 | `SRTrack.mod2` を読めない、SRT ファイルを読めない、有効なSRT字幕がない | Object の入力または導入状態を確認する必要があることを示す。 |

分類は文字色と接頭辞で見分けられる。通常 Object の動画参照なしは赤いエラーとして扱わない。Preview の画面内メッセージを共通診断ログへ記録する経路は、引き続き将来の検討とする。

Preview は描画時に、公開Lua APIでSRTrack ObjectよりLayer 1側を探索し、上側の直前動画Objectを特定する。中間点がない動画では、動画開始フレームとの差をフレームレートで秒へ換算し、動画の途中から置かれた場合も動画内の対応位置から表示する。中間点を持つ動画のソース時刻は 2.2.1 のとおり `SRTrack.mod2` へ委譲する。モジュールは Unicode を含む SRT パスの読込に加え、公開 SDK の区間・トラック値 API を用いる時刻計算を担う。常時監視やプロジェクト全走査は行わない。

`SRTrack.mod2` の時刻計算を呼び出せない場合は、Preview を停止せず従来の単一区間計算へフォールバックする。現時点ではこのフォールバック自体を画面へ表示しないため、中間点がある動画では Preview の時刻精度が下がる可能性がある。次回以降に追加予定の Preview 診断モードでは、モジュール計算の成否とフォールバックを報告に役立つ情報として表示対象にする。

### 公開 Lua API による上側探索

[AviUtl2 Lua リファレンス](https://docs.aviutl2.jp/lua/)の `obj.getvalue(layer, effect, item)` は、指定レイヤー（1から）の現在時刻にあるObjectの設定値を取得し、対象がない場合は `nil` を返す。Preview は `obj.layer - 1` からLayer 1側へ順に、標準 `動画ファイル` の `再生位置` を取得できる最初のレイヤーを参照先とする。同じレイヤーから再生速度・ループを取得し、`obj.getvalue("layerN.frame_s")` で動画開始フレームを得る。

この経路は、上側にある最も近い動画 Object を探索するものであり、Objectの描画ごとに上側レイヤーだけを確認する。プロジェクト全体の走査やMonitorを必要としない。フィルタ等の非動画Objectを間へ置いた Preview／Exporter の実機一致は確認済みである。

Lua API で標準動画の再生範囲として直接取得できるのは開始位置 `P` である。Preview の終端は、同じタイムライン範囲へ配置される SRTrack Object 自身の終端で表す。したがって Preview の時間変換には `P`、再生速度、ループ、`全長 D` を使用する。

## 2.7 SRT の入力形式

初期版は UTF-8 を対象とする。BOM の有無、CRLF／LF、末尾空行、複数行本文を検証対象にする。各字幕は開始時刻、終了時刻（整数ミリ秒）、本文、元ファイル内順序へ解析する。内部区間は `[開始, 終了)` とする。

不正 UTF-8、不正時刻、番号欠落・重複、時刻順でない字幕、重複区間、本文の空行やタグ、大きいファイル、相対パス、外部更新の扱いは継続検討する。曖昧な入力を黙って変更しない。

## 2.8 追加メニューと Preview

Object 追加メニューでは、三つの Object を `SRTrack` の下へまとめる。

- `SRTrack` → `SRTrack Object`
- `SRTrack` → `SRTrack Object (fix)`
- `SRTrack` → `SRTrack Object (txt)`

三者とも `字幕プレビュー` を持つ。`SRTrack Object` は上側の直前動画Objectの開始位置・速度・ループと開始位置差を用いる。`SRTrack Object (fix)` は自身が保持する再生位置・速度・ループ・全長と Object 内時刻を用いる。`SRTrack Object (txt)` は Object の表示範囲と入力テキストを用いる。いずれも Preview は編集画面専用で、動画出力には描画しない。
