# 2. SRT Object と入力データ

## 2.1 二つの Object

SRTrack は、一つの Object に動画追従と手動再生設定を同居させない。SRT を字幕ソースとして扱う共通の役割を、時間変換の基準が異なる二つの Object に分ける。名称は当面の仮称である。

| Object | 時間変換の基準 | 主な用途 | 状態 |
| --- | --- | --- | --- |
| SRTrack Link Object | 同じ時刻に直上レイヤーにある標準 `動画ファイル` Object | レンダリング済み動画と対応する SRT | 次期実装 |
| SRTrack Clip Object | Object 自身の再生開始位置と速度 | 動画と独立した SRT の配置 | 次期実装 |

両者は SRT ファイルを読み、Exporter の字幕ソースになり、編集用字幕プレビューを任意に表示する。プレビューは確認専用であり、動画書き出し中は描画しない。Exporter の統合・結合・オフセット結果とプレビュー表示の一致は要件にしない。

## 2.2 SRTrack Link Object

Link Object は動画に付随する字幕側 Object である。保持する項目は `SRT ファイル`、`動画全長 D`、`字幕プレビュー` とする。`D` は画面へ表示し、Importer が初回配置時に元動画の全長として設定する。`D` はループの周期だけに使い、移動・分割・伸縮では変更しない。AviUtl2 の UI 上で手動変更できる場合は動画との整合性が崩れうるため、変更は非推奨とする。

再生位置 `P`、再生範囲終端 `E`、再生速度、ループ再生は Link Object に保存しない。Object が存在する各時刻で、直上レイヤーにある標準 `動画ファイル` Object の現在値を直接参照する。動画と Link Object をグループ化することは、移動・分割・伸縮時にこの上下関係を保ちやすくする補助であり、参照の成立条件ではない。

`SRT ファイル` は利用者が指定する独立した参照である。Importer は同名 SRT を初期値として設定するだけで、動画ファイルの変更後に SRT パスを自動追従・差し戻ししない。別名の動画と SRT を組み合わせる手動利用を妨げない。

## 2.3 SRTrack Clip Object

Clip Object は動画を参照しない。`SRT ファイル`、再生開始位置 `P`、再生速度、`字幕プレビュー` と Object 自身のタイムライン範囲を保持する。`E`、`D`、ループ再生、動画とのグループ関係は持たない。SRT の最終字幕を過ぎた後は字幕を表示・出力せず、途中で終了したい場合は Object の終端を使う。

## 2.4 Link Object の参照失敗とプレビュー

Link Object の存在する時刻に直上レイヤーの標準動画がない場合、その時刻は有効な字幕ソースではない。Preview は編集画面にエラーを表示し、Exporter は当該区間を出力せず警告として集計する。SRT の読込失敗や不正な設定も、空字幕として黙って扱わず編集画面に診断を表示する。診断は動画書き出し中には描画しない。

Preview は `SRTrack.mod2` を通じ、描画時に編集コンテキストから動画を参照する方式を採用予定である。初回の Object 特定結果をキャッシュし、常時監視や毎フレームのプロジェクト全走査を避ける。実装可能性と性能は実機で検証する。

## 2.5 SRT の入力形式

初期版は UTF-8 を対象とする。BOM の有無、CRLF／LF、末尾空行、複数行本文を検証対象にする。各字幕は開始時刻、終了時刻（整数ミリ秒）、本文、元ファイル内順序へ解析する。内部区間は `[開始, 終了)` とする。

不正 UTF-8、不正時刻、番号欠落・重複、時刻順でない字幕、重複区間、本文の空行やタグ、大きいファイル、相対パス、外部更新の扱いは継続検討する。曖昧な入力を黙って変更しない。
