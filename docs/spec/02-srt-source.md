# 2. SRT Object と入力データ

## 2.1 二つの Object

SRTrack は、一つの Object に動画追従と手動再生設定を同居させない。SRT を字幕ソースとして扱う共通の役割を、時間変換の基準が異なる二つの Object に分ける。

| Object | 時間変換の基準 | 主な用途 | 状態 |
| --- | --- | --- | --- |
| SRTrack Object | 同じ時刻に直上レイヤーにある標準 `動画ファイル` Object | レンダリング済み動画と対応する SRT | `SRTrackObject.obj2`、初期実装・簡易確認済み |
| SRTrack Object (Standalone) | Object 自身の再生開始位置と速度 | 動画と独立した SRT の配置 | `SRTrackObject(Standalone).obj2`、初期実装 |

両者は SRT ファイルを読み、Exporter の字幕ソースになり、編集用字幕プレビューを任意に表示する。プレビューは確認専用であり、動画書き出し中は描画しない。Exporter の統合・結合・オフセット結果とプレビュー表示の一致は要件にしない。

## 2.2 SRTrack Object

SRTrack Object は動画に付随する主用途の字幕側 Object である。保持する項目は `SRT ファイル`、`動画全長 D`、`字幕プレビュー` とする。`D` は画面へ表示し、Importer が初回配置時に元動画の全長として設定する。取得不能時は `0` を設定する。`D` はループの周期だけに使い、移動・分割・伸縮では変更しない。AviUtl2 の UI 上で手動変更できる場合は動画との整合性が崩れうるため、変更は非推奨とする。

再生位置 `P`、再生範囲終端 `E`、再生速度、ループ再生は SRTrack Object に保存しない。Object が存在する各時刻で、直上レイヤーにある標準 `動画ファイル` Object の現在値を直接参照する。動画と SRTrack Object をグループ化することは、移動・分割・伸縮時にこの上下関係を保ちやすくする補助であり、参照の成立条件ではない。

`SRT ファイル` は利用者が指定する独立した参照である。Importer は同名 SRT を初期値として設定するだけで、動画ファイルの変更後に SRT パスを自動追従・差し戻ししない。別名の動画と SRT を組み合わせる手動利用を妨げない。

## 2.3 SRTrack Object (Standalone)

SRTrack Object (Standalone) は動画を参照しない補助的な Object である。`SRT ファイル`、再生開始位置 `P`、再生速度、`字幕プレビュー` と Object 自身のタイムライン範囲を保持する。`E`、`D`、ループ再生、動画とのグループ関係は持たない。SRT の最終字幕を過ぎた後は Preview を表示せず、途中で終了したい場合は Object の終端を使う。Exporter への出力対応は後続開発事項である。

## 2.4 SRTrack Object の参照失敗とプレビュー

SRTrack Object の存在する時刻に直上レイヤーの標準動画がない場合、その時刻は有効な字幕ソースではない。Preview は編集画面に専用エラーを表示する。Exporter は当該区間を単に字幕がない区間として扱い、警告や失敗にせず出力を継続する。SRT の読込失敗や不正な設定も、空字幕として黙って扱わず編集画面に診断を表示する。診断は動画書き出し中には描画しない。

Preview は描画時に Lua の `obj.getvalue()` で直上レイヤーの動画 Object の設定値と開始フレームを直接参照する。SRTrack Object 自身の開始フレームとの差をフレームレートで秒へ換算し、動画の途中から置かれた場合も動画内の対応位置から表示する。`SRTrack.mod2` は Unicode を含む SRT パスの読込だけを担う。常時監視やプロジェクト全走査は行わない。実装可能性と性能は実機で検証する。

Lua API で標準動画の再生範囲として直接取得できるのは開始位置 `P` である。Preview の終端は、同じタイムライン範囲へ配置される SRTrack Object 自身の終端で表す。したがって Preview の時間変換には `P`、再生速度、ループ、`D` を使用する。

## 2.5 SRT の入力形式

初期版は UTF-8 を対象とする。BOM の有無、CRLF／LF、末尾空行、複数行本文を検証対象にする。各字幕は開始時刻、終了時刻（整数ミリ秒）、本文、元ファイル内順序へ解析する。内部区間は `[開始, 終了)` とする。

不正 UTF-8、不正時刻、番号欠落・重複、時刻順でない字幕、重複区間、本文の空行やタグ、大きいファイル、相対パス、外部更新の扱いは継続検討する。曖昧な入力を黙って変更しない。

## 2.6 追加メニューと Preview

Object 追加メニューでは、二つの Object を `SRTrack` の下へまとめる。

- `SRTrack` → `SRTrack Object`
- `SRTrack` → `SRTrack Object (Standalone)`

両方とも `字幕プレビュー` を持つ。`SRTrack Object` は直上動画の開始位置・速度・ループと開始位置差を用いる。`SRTrack Object (Standalone)` は自身が保持する再生位置・速度と Object 内時刻だけを用いる。いずれも Preview は編集画面専用で、動画出力には描画しない。
