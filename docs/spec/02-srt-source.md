# 2. SRTrack Object と入力データ

## 2.1 役割

SRTrack Object の主目的は、外部 SRT をどのようにタイムラインへ対応づけるかを保持する、SRTrack Exporter の字幕ソースである。`SRT ファイル`、秒単位の再生位置 `P` と再生範囲終端 `E`、動画全長 `D`、百分率の再生速度、`字幕プレビュー` の設定を持つ `.obj2` を実装済みである。

エクスポート時、SRTrack Exporter は対象オブジェクトを識別して、ファイル参照と再生設定を取得し、SRT を解析する。エクスポート用の解析・時間変換は Exporter 側を正とする。

編集用プレビューは例外として、現在表示すべき SRT 字幕を SRTrack Object 側でも解析・計算する。これは画面確認のための独立した補助機能であり、Exporter の統合・結合・オフセット結果との一致を要件にしない。ファイル出力中はプレビューを描画しない。

### 編集用プレビューの読込失敗

SRT のファイル参照は Exporter と編集用プレビューで別々に利用する。プレビューは純粋 Lua の `io.open()` に依存せず、`SRTrackPreview.mod2` の公式スクリプトモジュール API を通じて UTF-8 のパスを Windows の Unicode ファイル API で開く。これにより日本語を含むパスを扱う。

この場合、単に空の字幕として扱って無表示にしてはならない。編集画面ではプレビュー位置に読込失敗であることと、確認対象（ファイル参照または Lua 側の読込）を明示する。これを SRT 字幕本文の代わりに表示するのは編集時だけであり、ファイル出力中は表示しない。

プレビューで字幕本文または失敗表示を出す際は、スクリプト終了時の暗黙描画へ依存せず、明示的に描画する。これにより通常のオブジェクト描画設定との順序に依存しない表示を目指す。

## 2.2 動画とのペアと同期

SRTrack Object は、対応するレンダリング済み動画の字幕側の相方として扱う。動画ファイルをタイムラインへドロップした際、同名の SRT を参照する SRTrack Object を生成し、動画オブジェクトとグループ化する方式を初期版の目標とする。Importer による自動生成とグループ化は初期実装済みである。

グループ化は配置をそろえるだけの補助ではない。動画オブジェクトに対する移動、分割、伸縮、再生開始位置の変更、速度変更の編集結果を SRTrack Object 側でも同じ時間的挙動として扱い、元 SRT の参照範囲を対応させるための関係である。

ただし、伸縮と分割を正確に扱うには、再生開始位置だけでなく、対応する動画の再生範囲の終端位置も必要である。SRT の最終字幕時刻は元動画の長さを表さないため、SRTrack Object 単体から終端位置を推定してはならない。SRTrack Importer が取込時に動画オブジェクトと同じフレーム境界の終端で `E` を初期化する構成を採用する。取込後の分割・伸縮への自動追従は、グループ内の標準動画の更新結果を Object へ反映する常駐処理として検討中である。ただし、取込コンポーネントとこの継続同期を同じプラグイン単位に置くかを含む名称・責務の再定義が必要なため、実装は保留とする。

動画オブジェクトと SRTrack Object が同一の挙動を得るための具体的な実装方法と、SDK で取得・設定できる値は実機で検証する。SDK で完全な同期を実現できない操作は、対応範囲を明示する。

## 2.3 オブジェクトに必要な情報

現行 Object は次の項目を保持する。将来の拡張時は、項目名・UI・保存形式を SDK と実機で確認する。

| 情報 | 用途 | 状態 |
| --- | --- | --- |
| SRT ファイル参照 | 読み込む字幕ファイルの指定 | 実装済み |
| 再生位置 `P` | オブジェクト開始時に参照する SRT 元時刻（秒） | 実装済み |
| 再生速度 | SRT とシーンの時間変換（百分率） | 実装済み |
| 再生範囲の終端 `E` | 元動画／SRT の利用範囲を定義する。Importer が動画と同じフレーム境界終端を設定する | 実装済み・簡易確認済み |
| 動画全長 `D` | Importer が設定する動画の基準長。移動・分割・伸縮で変化させず、将来のループ処理だけに使う | 実装済み・簡易確認済み |
| 識別子 | 将来の表示・参照・複数ソース選択 | 任意候補 |

オブジェクト自身のシーン上の開始・終了位置は、通常のタイムライン情報から取得する。初期版では、正の固定速度・ループなしを対象とする。

`P`、`E`、再生速度、`D` は、対応する動画オブジェクトとの同期を前提とした自動設定値である。AviUtl2 上では利用者がこれらを手動変更できるが、変更すると動画との対応が崩れ、出力字幕や将来のループ結果が正しくなくなる可能性がある。手動変更は非推奨とし、編集不能化や自動的な差し戻しは行わない。Object の UI と利用案内でこの注意を明示する。

手動変更の有無を検出・記録・判定する状態は持たない。継続同期を実装する場合は、動画側で本体が更新した `P`・`E`・再生速度を Object へ反映する案を基準に、手動値が反映される結果を許容する。

### 再生位置の UI

内部では再生開始位置を `P`、再生範囲終端を `E` と区別する。現行 UI では両者を別々の設定項目として表示するが、単位と初期値は標準動画に合わせる。再生速度も標準動画と同じ百分率表示に合わせる。


## 2.4 SRT の入力形式

初期版は UTF-8 を対象とする。BOM の有無、CRLF／LF、末尾空行、複数行の本文を検証対象にする。

各字幕は少なくとも次の情報へ解析する。

- 開始時刻（整数ミリ秒）
- 終了時刻（整数ミリ秒）
- 本文（複数行を保持）
- 元ファイル内の順序

基準の時刻表記は `HH:MM:SS,mmm` とする。内部区間は開始を含み終了を含まない `[開始, 終了)` を候補とする。

## 2.5 未決定の入力処理

以下は実装前に方針を決める。

- 不正 UTF-8、不正時刻、番号の欠落・重複、開始と終了の逆転を検出した場合、全体を中止するか、該当ブロックを警告付きで除外するか。
- 時刻順でない字幕、重複する字幕、本文中の空行、前後空白、HTML 風タグをどこまで保持するか。
- 大きいファイル、字幕件数、本文サイズの上限。
- ファイル参照を絶対パス、プロジェクト基準の相対パス、または両方のどれで保存するか。
- 外部で更新した SRT を、エクスポート時に読み直すか、取り込み時の内容を固定するか。
- 動画と同名の SRT がない場合、複数ある場合、動画・SRT の移動や名前変更をした場合の対応。

曖昧な入力を黙って変更しない。除外・中止・部分出力のいずれでも、利用者が確認できる警告を出す。
